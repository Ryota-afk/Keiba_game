# 優駿達の蹄跡（ahonoora.com）から取った中央重賞の結果表

- 出典：優駿達の蹄跡 `https://ahonoora.com/`（運営者が`help.html`で「事実の伝達に過ぎず著作物ではない。
  ご自由にご利用くださって結構です」と明記。`design/rights-check.md`§8・2026-09-07にユーザーが3本目の出典として承認）。
- `fetch.py`：年一覧`grade_YYYY.html`→各レースの結果表ページを取る（1秒待ち・再試行・再開可能）。
  生のHTMLはリポジトリに入れない（作業場所のみ）。
- `parse.py`：結果表→`parsed/YYYY.json`。ここには`YYYY.json.gz`として置く。
- 列：着順・枠番・馬番・馬名・性齢・斤量・騎手・調教師・タイム（着差。タイムは1着のみ）・人気。
  見出しから：回次・レース名・開催日・競馬場・R・条件・芝/ダ・距離・回り・天候・馬場・1着本賞金。
- ⚠️`isArab: true`（アングロアラブ系）はサラブレッドの世界に入れない。障害は名前・距離で判別が要る。
- ⚠️⚠️**`isArab`は取りこぼす。** 旧書式の見出し（`■ 第NN回 …競馬場 芝NNNNメートル`）のページは
  条件欄が無く、`condition`も`prize1`も`None`になり、`isArab`が`False`のまま残る。
  実例：**タマツバキ記念（春・秋）はアラブのレースだが`False`**（同年のアラブ大賞典・アラブ王冠と
  出走馬が重なることで判明。2026-09-12）。⭐アラブかどうかは出走馬の重なりで確かめること。

## 解析と重賞データへの流れ（2026-10-13）
1. `fetch.py`（生のHTMLを`raw/YYYY/`へ）→ 2. `python3 -I parse.py 1988 1989 …`（**年を必ず指定**。引数なしは`raw/`の全年を作り直す）
→ `parsed/YYYY.json` → 3. `YYYY.json.gz`へgzip（`gzip.compress(parsed, 9, mtime=0)`）→ 4. `node tools/build-graded-races.mjs 1972 2024`
→ `node tools/verify-graded-races.mjs` → `node tools/build-real-horse-names.mjs`。規則は`arch/race-program.md`§1。
- `prize1`（円）：「1着1億300万円」の億・万、「1億3,200円」（万の脱字）、旧書式の「本賞金（万円） 1着3,000」を読む。読めなければ`null`。
- `surface`：芝／ダ→`turf`／`dirt`。見出しに「m（障害」があれば`jump`（1995年以降の新書式。名前に「障害」の無いジャンプ系の重賞も分かる）。
- `course`：日付の直後の「東京11R」か「○○競馬場」から読む（見出し先頭の一致だと「中山記念」「京都金杯」で名前の中の場名を拾っていた）。
- 現在`YYYY.json.gz`は1972〜2024年（2009〜2024年は2026-10-14に追加。`raw/`は1988〜2024年）。
- `prize1`の書式は5種：「本賞金 1着5,200万円」「1着1億300万円」「1着1億3,200円」（万の脱字）「本賞金（万円） 1着3,000」（旧書式）
  「本賞金（円） 1着4,100万/2着…」（中日新聞杯2018〜20のみ・2026-10-14に追加）。2009〜2024年は全レース読める。
