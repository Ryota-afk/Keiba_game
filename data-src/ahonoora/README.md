# 優駿達の蹄跡（ahonoora.com）から取った中央重賞の結果表

- 出典：優駿達の蹄跡 `https://ahonoora.com/`（運営者が`help.html`で「事実の伝達に過ぎず著作物ではない。
  ご自由にご利用くださって結構です」と明記。`design/rights-check.md`§8・2026-09-07にユーザーが3本目の出典として承認）。
- `fetch.py`：年一覧`grade_YYYY.html`→各レースの結果表ページを取る（1秒待ち・再試行・再開可能）。
  生のHTMLはリポジトリに入れない（作業場所のみ）。
- `parse.py`：結果表→`parsed/YYYY.json`。ここには`YYYY.json.gz`として置く。
- 列：着順・枠番・馬番・馬名・性齢・斤量・騎手・調教師・タイム（着差。タイムは1着のみ）・人気。
  見出しから：回次・レース名・開催日・競馬場・R・条件・芝/ダ・距離・回り・天候・馬場・1着本賞金。
- ⚠️`isArab: true`（アングロアラブ系）はサラブレッドの世界に入れない。障害は名前・距離で判別が要る。
