# JRA公式の番組表PDF（2026年）

出典：JRA公式 `https://www.jra.go.jp/keiba/program/2026/pdf/bangumi/<場><回>.pdf`（42ファイル）。
`design/rights-check.md`の承認済み出典。⚠️**PDFそのものはここに置かない**（取得は`fetch_bangumi.py`）。

## 何のために取ったか
決定A（1日の11レースに芝・ダート・距離・クラスをどう配るか）の材料。
⚠️**1974年の番組表は存在しない**ので、今のJRAの配り方を測り、1974年の実測（馬のページから拾える
一般競走の19%）でずれを直す（質問9＝(ア)・2026-09-13にユーザーが決定）。
⚠️⚠️**ユーザーの制約：オープン・リステッド・重賞は2026年の型で増やさない。**
この3つの本数は史実の側に合わせる。リステッドは2019年からの格付けなので1974〜2003には置かない。

## 文字化けの直し方（`pdfmap.py`）
埋め込みフォントにToUnicodeが無く、`extract_text`は化ける。
- **数字**：`U+030C`〜`U+0315`が0〜9。カンマは`ɼ`。
- **語**：`WORDS`の対応表（新馬・未勝利・オープン・N勝クラス・混合・牝・指・別定・定量・馬齢・
  ハンデ・特指・歳・以・上・障・芝・ダ）。
- **座標**：`extract_text(visitor_text=...)`で1セルずつ(x,y)を取る。日付の列は丸数字
  `ᶃᶄᶅ…`（`U+1D83`から）で始まる。**左の種別列の右端＝最初の丸数字x −（列の幅×0.55）**。

## `agg_bangumi.py`（種別ごとの年間本数・⭐検算に通っている）
左端の「種別（計）」列だけを読む。⭐**42開催すべてで「（計）の合計＝丸数字の個数×12」が成立**。
- ⚠️`X-1.pdf`と`X-2.pdf`に分かれた開催は、**-1側に開催全体の（計）が載っている**。
  日数は-2側の丸数字の最大を使う。
- ⚠️（計）の数字は**種別名の行の5〜22pt下・x≧左列の右端×0.70**にある。この制限が無いと、
  左に寄っている年齢の数字（「2」歳など）を拾って壊れる。
- ⚠️種別名の行に年齢の文字が混ざることがあるので、**完全一致ではなく含むかで判定する**。

## `dist_bangumi.py`（距離と芝・ダート）⚠️まだ検算に通っていない
日付の列の「距離（芝/ダ）」を数える。⚠️**拾えた3,648個はあるべき3,468個より180多く、
17%は芝かダートか判別できていない。** 表の外（重賞の一覧・負担重量の表）を拾っているとみられる。
