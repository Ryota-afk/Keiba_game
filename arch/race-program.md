# 番組表（1年のレースをどう並べるか）

⭐**正本。** `ARCHITECTURE.md`§15の「クラスごとのレース数の配分」の答え。
決定A・質問8〜11（2026-09-12〜14にユーザーが決定）の結果を置く。経緯は`devlog/wave06.md`。

## 1. 重賞は年ごとの実データ（質問8＝(ア)）

⭐**その年に実在した重賞を、週・競馬場・距離・名前ごとそのまま置く。** 30年ぶん持つ。
出典は優駿達の蹄跡の結果表（`data-src/ahonoora/`）。1974年は100本（平地サラブレッド84・障害8・アラブ8）。
- **障害とアラブはゲームに出さない**（質問5）。1974年に番組表へ並ぶ重賞は**84本**。
- **グレード（G1/G2/G3）は1984年から出す。** 障害のグレードは1999年から。
- ⚠️**リステッド（L）は置かない**——JRAが2019年に付け始めた格付けで、1974〜2003年には無い。
- ⭐**開催の並び（どの週にどの競馬場が開くか）は今のJRAの52週の並びを毎年固定して使う**
  （質問20＝(イ)・2026-09-15にユーザー決定。`design/jra-race-calendar.md`§3の並び＝関東13・関西13・
  第3場10開催、288日）。⚠️Claudeは「重賞がその週に開いていない競馬場で行われる矛盾が出る
  （1974年の皐月賞は東京、今の並びでは第16週は中山）」を示したうえでの決定。
  ⚠️矛盾の処理（重賞の競馬場を実データどおりに追加で開くか、その週に開いている場へ移すか）は質問21。

## 2. 1日は11レース（1997年まで）／12レース（1998年から）

根拠：Wikipedia「中央競馬」。⚠️**1974年の開催日数は未確認**（288日は今の開催の並びから出した数）。
288日×11＝年3,168本。

## 3. クラスの配り方（決定A）

⭐**クラスは1勝・2勝・3勝クラスの3段。昇級は勝った回数**（質問10＝(イ)）。
⚠️1974年の史実は賞金別11段（200〜1300万下）だが**採らない**。
⚠️**収得賞金は別に持つ**——重賞の出走順はJRAの規則どおり収得賞金の多い順（`design/jra-entry-rules.md`）。

**1974年の場合**（年3,168本＝288日×11）：

| 種別 | 1年の本数 | 1日あたり | 出どころ |
|---|---|---|---|
| 新馬 | 305 | 1.06 | 残り2,994本の10.2%（2026年の平地の割合） |
| 未勝利 | 1,138 | 3.95 | 同 38.0% |
| 1勝クラス | 889 | 3.09 | 同 29.7% |
| 2勝クラス | 449 | 1.56 | 同 15.0% |
| 3勝クラス | 213 | 0.74 | 同 7.1% |
| オープン以上 | 174 | 0.60 | ⭐**先に固定する**（重賞84＋オープン特別90） |
| **計** | **3,168** | **11.00** | |

⚠️⚠️**オープン・リステッド・重賞は2026年の型で増やさない**（ユーザーの制約）。
⭐**手順**：①その年に実在した重賞の数を数える（1974年は84本＝平地サラブレッドのみ）
②オープン特別をその1.07倍と置く（84×140/130＝90本）③残りを上の割合で新馬〜3勝クラスに配る。

残りが約140本だったので、その比を借りただけ。馬ごとの戦績表を取り終えたら実測して置き換える。

## 6. 年齢と牝馬限定

- **2歳戦は6月から**（根拠：史実の馬24頭のデビュー月の実測——6月1・7月7・8月6・9〜11月9・

## 7. 出走頭数と、相手の選び方（決定3・質問14＝(A)・2026-09-15）

**出走頭数**は実測の分布から引く（史実の馬24頭・527走の実測）：

| 頭数 | 割合 |
|---|---|
| 5〜8 | 30.6% |
| 9〜12 | 38.0% |
| 13〜16 | 23.3% |
| 17〜18 | 3.2% |
| 19〜26 | 4.9% |

平均10.98・真ん中10。⚠️**18頭立ては3.2%しかない。出馬表の画面は10頭前後を前提に作る。**
⚠️`src/domain/raceOutcome.js`の`MIN_FIELD_SIZE=6`〜`MAX_FIELD_SIZE=18`の一様抽選は根拠が無い。差し替える。

**相手の選び方**：⭐**現役馬を全部持ち（1974年は5,800頭＝145厩舎×40）、毎週コンピュータの厩舎が
「次にどのレースへ出すか」を決める。** 枠に対して希望が多いときは**収得賞金の多い順**で絞る
（JRAの規則・`design/jra-entry-rules.md`）。プレイヤーが乗るレースだけ`src/sim/`の本物の計算を回し、
他のレースは強さ比べで着順を決める。

⭐**時間の実測（`tools/bench-weekloop.mjs`）：30年＝1,560週・95,160レース・延べ1,051,503走で1,523ms。
1週0.98ms・1年51ms。** ⚠️**これは下限**——1頭の判断に距離の照合・芝ダの適性・厩舎のローテの型・
出走登録が加わる。⭐**それでも数倍までなら1週5ms以内に収まるので、(A)で進めてよい。**
