### 能力（9軸）

⚠️**表示形式はウイポ基準**：**スピードとスタミナのみ数値。残り7つは記号（G〜S）。**

| 軸 | 表示 | 着順を何着ぶん動かすか |
|---|---|---|
| スピード | **数値** | 直線で3〜4着分 |
| スタミナ | **数値** | 適距離を外したときだけ大きく垂れる（0〜8着分）。⚠️**非対称**：適距離より短いレースでは能力があまり落ちず、**長いレースでは直線で垂れる** |
| 瞬発力 | 記号 | 末脚。2〜4着分。**勝負根性との大小が脚質を決める** |
| 勝負根性 | 記号 | 最後の粘り。1〜3着分。**瞬発力との大小が脚質を決める** |
| 柔軟性 | 記号 | 単独では動かさない。**スタミナと組んで適距離の「幅」を決める** |
| 賢さ | 記号 | ⭐**着順を直接は動かさない。判断カードの効き幅を動かす** |
| 健康 | 記号 | ⭐**着順を動かさない。落馬確率・離脱期間・疲労を動かす** |
| **パワー** | 記号 | **坂と重馬場**。⭐中山・阪神の直線の坂で失速する |
| **精神力** | 記号 | **遠征**（地方・海外・東西の移動）で弱体化しない |

⚠️**脚質と適距離は導出値**。別枠で持たない。
⭐**パワーと精神力は第1弾-Eで足した**——B2で地方61レース・B8で海外20〜30を入れて遠征の
仕組みができ、F4でコース形状に坂が入ったため（`TODO.md` #2の条件が揃った）。

### ⭐ 適応能力（レース傾向への適応・第1弾-Eで確定）

**血統から導出し、レースで育つ。** ⚠️独立した軸として手で付けない（読む量を増やさない）。

| 適応 | 対応するレース傾向 | 血統の由来 |
|---|---|---|
| 瞬発 | **瞬発戦**（最終盤に一気にペースが上がる） | 日本型の系統 |
| 持久 | **持久戦**（中盤からずっとペースが上がる） | 欧州型の系統 |
| 消耗 | **消耗戦**（スタート直後から速い） | 米国型の系統 |

⭐**育つ経路：同じ傾向のレースに出る／判断カードでその傾向に対応する作戦を選ぶ。**
⚠️**育つ速さを間違えると全部の馬が全適性を持つ。** 計測すること。

**開示の対象外**（2026-09-02・ユーザー）：適応能力は**血統表を見れば分かる**。確率開示の2プール
（§3 開示）には入れない。血統表の系統（日本型／欧州型／米国型）を読み取る仕事をプレイヤーに残す。

**性別**（牡・牝・セン）を持ち、**レースにも効く**：牝馬限定戦があり、斤量も変わる。
⚠️牝馬の引退は**史実馬は史実通り、架空馬は早め**（繁殖に入る）。
⚠️**レース体系に牝馬限定の系統を1本足す必要がある**（B-1で決めた体系の更新）。

### 馬の一生（第1弾-Eで確定）

| 項目 | 仕様 |
|---|---|
| 成長型 | **4種類程度**。ピークの年齢が違う（早い型は2歳後半〜3歳前半、遅い型は4歳後半以降） |
| 能力の成長 | **後天的に伸びる。⚠️ただしスタミナは伸びない**（⭐長距離適性は生まれつきで決まる＝見抜く価値のある軸） |
| 引退 | **年齢と成績と怪我**。⚠️**史実馬は史実の引退年が上限**で、怪我で早まる |
| 出走数 | 1頭あたり**年6.3走**（実測の逆算）。キャリア2〜3年で**生涯15〜20走** |

⚠️⚠️**主戦の座との関係**：馬のキャリアが2〜3年なので、**1頭との関係は実質2〜3年**。
常時5頭が主戦なら**30年で延べ40〜50頭**と深く関わる（§2）。

### 出走馬の決定（H・第1弾-Eで確定）

**各馬が次走の目標を持ち、調教師が決める。**
馬ごとに「前走からの週数・クラス・適距離・芝ダート」があり、調教師が条件に合うレースを選ぶ。
1頭年6.3走＝**約8週に1回**。⚠️史実馬の**重賞**は史実ローテ（下記）が優先する。

⚠️⚠️**未決（2026-09-04）**：ここは「⭐調教師の得意分野がここで働く——芝が得意な厩舎の馬は
芝を多く使う」としていたが、同日に**逆の決定**（得意分野は出走頻度ではなく馬の強さに効く／
依頼の条件は番組表の分布に従う）を出した。⚠️**その決定は第4弾へ送られ、まだ確定していない**
（`TODO.md` #24）。**どちらを採るかを決めるまで、この行を根拠に実装しないこと。**
⭐依頼一覧（§2）は、この決定の結果として「今週走る馬」から生成される。

### クラスの昇降（J・第1弾-Eで確定）

**勝利数で上がる。降級なし。** 未勝利→1勝→2勝→3勝→オープン。
⚠️オープン以上（G3・G2・G1）への出走条件は勝利数だけでは決まらない（実装の弾）。

### ⭐ 史実の拘束力

**史実は「どんな馬がいつ、どのレースにいたか」を決める。「何が起きたか」は決めない。**

| 史実が決める | ゲーム内で決まる |
|---|---|
| 生まれる年／引退する年（**上限**）／初期能力（⚠️戦績から**導く**）／**重賞のローテーション** | **着順**・獲得賞金・誰が乗るか |

⭐**矛盾が原理的に起きない。** プレイヤーがダービーで史実の2着馬に乗って勝っても、
史実の勝ち馬が2着になるだけで、どの馬も消えないし予定も狂わない。

⚠️**引退だけは例外で、怪我で早まる。** ⭐**自分が乗っているときの落馬で史実の名馬を
終わらせられる。** 「史実馬は怪我をしない」は採らない——**「史実馬に乗っていれば安全」という
歪んだ最適戦略**が生まれ、一番良い馬に乗っているときだけ緊張が消える。

### 馬の供給（第1弾-Eで確定）

| 項目 | 値 | 導出 |
|---|---|---|
| 現役馬 | **約7,600頭** | 190厩舎 × 平均40頭。競走回数からの逆算と一致 |
| 年間デビュー | **約2,400頭** | 現役7,600 ÷ 平均在籍3年 |
| **実名の馬** | **重賞に出走した馬**。年100〜200頭の桁（⚠️要実測）。常時**数百頭＝現役の数%** | 重賞出走表（事実） |
| **架空の馬** | 現役から実名を引いた残り（⚠️要実測。実名が数百頭なら**9割以上**） | 差分 |
| 馬主 | **100人前後**（⚠️実際のJRAは約2,000人） | 下記 |

**実名の線＝重賞に出走した馬**（重賞出走表で定義する）。
⚠️**ウイポの史実馬リストは使わない**——リストの「どの馬を選んだか」と能力値・成長型は
コーエーテクモの査定であり、データベースの著作物に当たる可能性がある（`design/rights-check.md`）。
⭐**生年・引退年・血統・戦績は事実**なので一次資料（JRA公式・Wikipedia）から取り、
**能力値と成長型は戦績から自分で導く**（何歳のどの重賞で何着だったか）。

⚠️**馬主を実数の1/20に減らした理由**：馬主の信頼が重賞の騎乗を決める（§6）ので、
2,000人だと30年で関わる馬主が分散しすぎ、**誰の信頼も積まれないまま終わる**
＝重賞への道が実質閉じる。⚠️代償として1人あたり約70頭と実態より大口になる。

### 血統（架空馬も全頭が父母を持つ）

⭐**父母は必ず繁殖馬である。走って終わった馬は誰の親にもならない。**

| 保存が要るもの | 数 |
|---|---|
| 繁殖牝馬 | 常時**約3,400頭** |
| 種牡馬 | 常時**約250頭** |
| 30年の延べ | **約1万頭**・1頭約30バイト → **約300KB** |

**保存の規則**：全頭が父母IDを持つが、**引退して繁殖に上がらなかった馬は世代が変わったら
捨てる**。⚠️**プレイヤーが乗った馬は別に残す。**

### 馬の名前

**大口馬主だけ冠名を持つ**（「冠名＋語幹」）。小口の馬は語の組み合わせ。

⭐**これで「今どの馬主の馬に乗っているか」を見せる専用UIが要らない。**
名前を見れば持ち主が分かり、⭐**分かるのは重賞に関わる馬主＝判断に必要な相手だけ**になる。
⚠️全馬主に冠名を与えると全部の馬名が同じ形式になり単調になる。

### レースカレンダー（第1弾-Eで確定）

⭐**1年分を持ち、月・週・曜日で固定して30年使い回す。** 30年分の日程を持たない。

| 対象 | 持ち方 | 量 |
|---|---|---|
| **一般競走**（年約3,325） | **実在の番組表を1年分**。競走名も実名 | 約170KB |
| **JRAの重賞**（年約130） | 雛形＋**創設年**でフィルタ。⚠️**重賞出走表（3,900レース×最大18頭）が実名の線・史実ローテ・成長型の推定・カレンダーの4つを兼ねる** | 1MB未満 |
| **地方のダートグレード** | ⚠️**61全部**（Jpn1〜Jpn3・JRA開催16を含む） | 小 |
| **海外** | **20〜30**：ドバイ(3月)→香港(4月・12月)→英仏の夏秋(6〜10月)→BC(11月) | 小 |

**週の定義**：**1年52週。月の第N週は実カレンダー通り**（月によって4〜5週）。

⚠️⚠️**地方を61全部にした理由**：中堅ランクで地方が解禁される（§8）のに、Jpn1だけだと
**解禁から頂点まで途中の目標が1つも無い**。芝には未勝利→条件→オープン→重賞の階段があるのに、
**ダートに階段が無い**状態になる。⭐**ダートで主戦になった馬を育てる先が要る。**
⚠️海外も同じ理由で20〜30にした（凱旋門賞だけだと海外解禁の報酬が空になる）。

**データ源**（実測で確認済み）：

| 用途 | 出典 | 範囲 |
|---|---|---|
| JRAの重賞（2002〜） | `jra.go.jp/datafile/seiseki/replay/YYYY/jyusyo.html`（**事実**） | ⚠️2001以前は403 |
| JRAの重賞（〜2001） | **Wikipedia各レース記事の歴代優勝馬・出走馬**（CC BY-SA 4.0・出典表示） | 未取得 |
| 地方のダートグレード | ⚠️NAR公式は転載が許諾制。**Wikipedia**（各競走の記事）を第一候補に | 未取得 |
| 史実馬の生年・引退年・血統・戦績 | ⚠️JBISは公開目的の利用を禁止（二次利用の申請窓口あり）。**Wikipedia**を第一候補に | 未取得 |
| 史実の馬主・調教師 | **JRA公式の騎手・調教師データ** `/datafile/`（**事実**） | 未取得 |
| 1年分の番組表 | JRA公式 `/keiba/program/YYYY/pdf/bangumi/*.pdf`（47ファイル）。⚠️**取得はできるが本文が読めない**（下記） | 未解決 |

⚠️⚠️**競馬ブック・netkeiba・アホヌラ館・JBISは使わない**——規約で公開目的の利用を明示的に禁止
（`design/rights-check.md`）。⭐**JRA公式（事実は対象外）とWikipedia（CC BY-SA 4.0）の2本に確定**（2026-09-02・ユーザー）。
⚠️Wikipediaのデータは別ファイルに分け、出典表示とライセンス表記を付ける。重要な値はJRA公式で突き合わせる。

⚠️**JRAのPDFの読み方**（2026-09-04に再調査して更新）：`poppler-utils`は入らないが**`pypdf` 6.16.2はプリインストール済み**で、
PDFの取得と構造の読み取りはできる。読めないのは**本文の文字**だけで、原因は
**Identity-H のCIDフォントに`ToUnicode`が無い**こと（`bangumi.pdf`・各開催の`bangumi/*.pdf`・
`datafile/seiseki/report/`の日別全成績PDF、いずれも同じ）。
⭐**glyph IDと文字の対応は1対1で固定されている**——数字は`̌̍̎̏̐̑̒̓̔̕`＝0〜9、
`ະউར`＝未勝利、`৽അ`＝新馬、`উΫϥε`＝勝クラス、`μ`＝ダ、というように読める。
**置換表を1回作れば全PDFを機械的に復号できる**見込み。⚠️ただし表の列構成は`extract_text()`で
失われるため、番組表の全数抽出には座標付き抽出が別途要る。
⚠️`www.jra.go.jp`はAkamaiが断続的に403を返す。同じURLでも数回リトライすれば200になる。
HTMLの経路（`datafile/seiseki/replay/YYYY/jyusyo.html`はShift_JIS）が読めるものはそちらを使う。

### ⭐ 重賞出走表（1つの表が4つの仕事をする）

**年約130重賞 × 30年 ＝ 約3,900レース、約54,600出走レコード。1MB未満。**

1. **史実ローテーション**——どの馬がどの重賞に出たか
2. **実名の線**——重賞に出た馬＝実名にする馬。⭐線の定義と表の中身が完全に一致する
3. **成長型と能力の推定材料**——何歳のどの重賞で何着だったか。⭐**ウイポを見ない**
4. **どの重賞がいつ行われたか**——カレンダー（B）の材料

⭐**1つの表が4つの仕事をする。** 余分なデータを一切持たない。

### 能力の開示（確率式）

⚠️**プールが2つに分かれている。**

| プール | 開く項目 | 開く条件 |
|---|---|---|
| **調教** | 賢さ・健康・脚質・**精神力**（4項目） | 朝の調教で乗る |
| **レース** | 適距離・スピード・瞬発力・勝負根性・底・**柔軟性**・**パワー**（7項目） | **プレイヤーが自分で判断した鞍** |

⭐**馬を知り切るには両方やる必要がある。** 調教に通い、かつレースで自分で乗る。
⚠️**預けた鞍・馬に任せた鞍では開示が進まない。**

**確率**（**暫定**・⚠️プールが2つに分かれたため再計算が必要）：
`p = 0.55 + 0.15 × 連続で開かなかった回数`（上限0.95）。初回のみ確率1.0。
