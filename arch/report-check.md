# ユーザーへ送る文の検査（CLAUDE.md §15の実体）

⚠️2026-09-08にユーザーが明示：**「このゲーム自体を遊んだことがなく、競馬についても
あまり知らない人でも理解できる説明」を仕組みにすること。**
きっかけは、こちらが書いた「前へ行く択が安くなる」「消耗だけ満額」という2つの言い方。
どちらも書き手の頭の中だけにある例えで、**何が何に対して安いのか・何の額が満ちているのかが
文中のどこにも書かれていなかった**。⚠️§15はそれ以前から「どんな人間が見ても理解できる
説明」と書いていたが、基準が言葉だけだったので守れなかった。⭐**言葉の一覧と、
毎回同じ文面のサブエージェント検査という2つの形にして、守れる形に変えた。**

## 1. いつ検査するか

- **説明を含むメッセージはすべて。** 数値・仕様・実装結果・案の提示を1つでも含むなら対象。
- 対象外は、1〜2行の短い返事（「直しました」「はい」「◯◯を先にやります」）だけ。

## 2. 手順（省略禁止）

1. 下書きをファイルに書く（`scratchpad/draft.md`など）
2. `node tools/check-words.mjs <ファイル>` を走らせる
   - **Aが1件でも出たら書き換える。0件になるまで送らない**（終了コードも1になる）
   - BとC（開発の言葉・競馬の言葉）は数えるだけ。⭐**初めて出てくる行に1行の説明が
     付いているかを自分の目で確かめる。** 説明を足せないなら、その言葉を使うのをやめる
3. 下の「サブエージェントへの依頼文」をそのまま貼って検査させる
4. 指摘を直してから送る

## 3. 言葉の3分類（一覧の実体は`tools/check-words.mjs`）

| 分類 | 扱い | 例 |
|---|---|---|
| A | **使わない。** 具体的な言葉に書き換える | 安く／満額／効く／解像度／次元／最適化／ちゃんと／など |
| B | 開発の言葉。**初出の行に1行の説明を付ける** | 乱数／中央値／フォーク／クランプ／定数／px/s |
| C | 競馬の言葉。**初出の行に1行の説明を付ける** | 脚質／道中／上がり3F／斤量／鞍上／持久力 |

⭐**言葉を足すときは`tools/check-words.mjs`の配列に足す。** ここの表は例示なので、
正本はスクリプト側。⚠️「一度説明したから次からは省く」はしない——1つのメッセージの中で
初出なら毎回説明を付ける（ユーザーは前のメッセージを見返さない前提で書く）。

## 4. 書き換えの実例

| 直す前 | 直した後 |
|---|---|
| 前へ行く選択肢が安くなる | 前へ行く選択肢を選んだときに減るスタミナの量が、以前より少なくなる |
| 消耗だけ満額のまま | スタミナの減る量だけは、割り引かずに以前と同じだけ減らしたまま |
| 200通りの乱数で測った | 200通りの初期値でレースを流して測った（初期値が違うと18頭の能力も展開も変わる） |
| 脚質を実データから取る | 逃げ・先行・差し・追込のどれで走る馬かを、実在の馬の記録から取る |
| 中央値 | 12回のうち真ん中の値 |
| 90%到達11.6秒 | 動く量の9割まで動くのに11.6秒（残りの1割はそのあとも動き続ける） |

## 5. サブエージェントへの依頼文（毎回そのまま使う）

```
あなたは日本語の文章検査係です。以下の下書き（競馬ゲームの開発者からユーザーへの
報告文）を読み、問題点だけを箇条書きで指摘してください。書き直しは不要です。

⭐読み手の前提：**このゲームを一度も遊んだことがなく、競馬についてもあまり知らない人。**
開発の言葉も競馬の言葉も知らない前提で、その人が読んで意味が取れるかだけを見てください。

検査項目：
1. 書き手の頭の中にしかない例えを使っていないか（「安くなる」「満額」「効く」
   「解像度」「次元」など）。使うなら、何が・何に対して・どれだけ、を数量で書いているか
2. 開発の言葉（乱数・中央値・フォーク・クランプ・定数・関数・px/s など）が、
   初めて出てくる場所で1行の説明なしに使われていないか
3. 競馬の言葉（脚質・道中・上がり3F・斤量・鞍上・持久力・まくり など）が、
   初めて出てくる場所で1行の説明なしに使われていないか
4. 一読して意味が確定しない文がないか（「つまりどういうこと？」と聞き返す余地のある文）
5. 根拠のない断定・未確認なのに断定している箇所がないか
6. 表の数字と本文の数字が食い違っていないか。割り算・引き算が合っているか
7. 数字に単位と「何と比べての値か」が書かれているか
8. 日本語として不自然な語法・文法の誤りがないか
9. 慣用句・体言止め・詩的な一文で誤魔化して締めていないか
10. 「〜など」「〜といった」で列挙を省略していないか

下書き：
---
（ここに下書きを貼る）
---
```
