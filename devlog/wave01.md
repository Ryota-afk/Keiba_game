## 2. 体験のスケール（A1・A2）

### 30分の予算——最初の試算と、その誤り

当初「30分で凱旋門賞クリアまで」と置き、キャリア6年・年4鞍で試算した。**これは誤りだった。**

配合の1回転に何年かかるかを数えると：

| 出来事 | 経過 |
|---|---|
| 3歳の馬Aに乗る | 0年 |
| Aが5歳で引退 | +2年 |
| 種付け・受胎 | +1年 |
| 産駒が生まれる | +1年 |
| 産駒が3歳でデビュー、自分が乗る | +3年 |
| **合計** | **7年** |

CLAUDE.md §0.5は「配合要素を強めに」、TODO #3は「自分が主戦だった馬同士の配合が騎手モードの
キャリアと繋がる要」としている。**キャリア6年では産駒が生まれる前にゲームが終わり、
配合は画面に出ることすらない。**

⚠️問題は30分という数字ではなく、**「30分で凱旋門賞クリアまで」というゴールの置き方**だった。
凱旋門賞は騎手キャリア終盤の出来事である。

### 直した形

- **完成版のキャリアは上限30年**。配合が4回転し（7年×4＝28年）、血統表が4代の深さを持つ。
- **第3弾で人間が通すのは、本編そのものの最初の30分**。デビューから初勝利、重賞への初挑戦あたり。
  別モードは作らない。
- ⚠️**却下した案**：本編と検証用で尺を分ける（短縮モードを別に持つ）。短縮モードで測った
  数字が本編に当てはまるかを毎回確かめる作業が増えるため。**先頭部分を歩くほうが、
  同じゲームなので確かめる作業自体が要らない。**

### 30年上限を置いた理由（「上限なし」を採らなかった理由）

⚠️**上限が無いとバランス計測の分母が存在せず、CLAUDE.md §10の計測が原理的にできない。**
30年という上限は「30年フルで走ったときの累積賞金・信頼・配合回数」を計算可能にする。
前作の「恒久的な使い道が13.7年目で枯渇」も、同じ物差しの上で再発チェックできる。

⚠️**逆のリスク**：30年に伸ばした分だけ、使い道が枯渇する危険も増える。賞金と信頼の使い道が
30年目まで残る設計が同時に必要。第1弾-Bで扱う。

### 判断の回数で測る（秒数ではなく）

レースは飛ばせる（`design/sakurai-ui.md` #10「必ず飛ばせる」）ため、再生時間は予算にならない。
代わりに**判断の回数**を予算とする。これはCLAUDE.md §0-3の「意味のある判断の密度」と一致する。

最初の30分の内訳（1判断あたり15秒として約120回が上限）：

| 判断の種類 | 回数 |
|---|---|
| 週の選択（年6週 × 6年相当） | 36 |
| レース中の判断カード（24鞍 × 2回） | 48 |
| 怪我などの対応 | 12 |
| 導入（キャラ作成） | 5 |
| **合計** | **101** |

## 3. 時間の粒度（B1）

**週次で進み、乗らない週は飛ぶ。**

原則：**プレイヤーが選べることがある週だけ止まる。選ぶことが何も無い週は、プレイヤーから見て
存在しない。** これにより「画面が出た時点で必ず判断が1つ乗っている」ことが作りで保証される
（§10の判断密度を事後に測るのではなく、構造で担保する）。

止まる週の候補（第1弾-Bで確定）：騎乗依頼が来た週／レース週／怪我からの復帰判定の週／
新しい馬と出会う週／馬主・調教師との関係が動く週／免許やクラスが変わる週。

⚠️**宿題（B4）**：飛んだ週に何も見せないと、30年が数百クリックになって時間が経った感覚が
消える。見せ方はCLAUDE.md §8のUI手順で決める。

⚠️**却下した案**：月次（前作と同じ）。6年で72回の「今月何をするか」が発生し、24回の予算を
3倍超える。収めるには「何も選べない月」を多く作ることになり、それはプレイヤーから見ると空打ち。

## 4. 騎乗の構造（B2）

名目上 年40鞍。**そのうち自分で乗る鞍をプレイヤーが先に選び、残りは預ける**（自動で結果だけ出る）。

これにより**このゲームの中心の判断が「どの馬に乗るか」に決まった。** 実在の騎手にとっても
中心の判断である。同時に、前作に無かった種類の痛みがここから自動的に生える——
**選んだ馬が走らない。断った馬が勝つ。**

⚠️前提が1つ増える：**乗る前に馬の良し悪しをどこまで見抜けるか（E2）**を決めないと、この選択は
サイコロを振るのと同じになる。前作の判断カードが実質1択に潰れていたのと逆方向の失敗——
**分散だけあって判断が無い**状態。§5で解決した。

## 5. 奪う器官と情報開示（C群・E2）— MAGI合議の記録

CLAUDE.md §0-2が前作最大の欠陥と名指しした領域なので、3ペルソナの合議＋悪魔の代弁者による
検証を通した。以下は結論に至る過程の記録。

### 5-1. 3ペルソナの主張（対立点）

- **ロマンチスト**：奪うべきは馬との関係。落馬で失うのは自分の脚ではなく、
  **動けない3ヶ月の間に乗っていた馬が別の騎手で勝つこと**。E2は数値で見せず、
  調教で乗った感触を言葉で返すべき。ゲームオーバーは置かない。
- **エンターテイナー**：面白いのは「断った馬が勝つ」瞬間。同じ週に3件来て1つしか受けられない形に
  する。受けなかった馬の結果は勝ったときと同じ重さで見せる。落馬は年1回未満に留めて事件にする。
  E2は見抜く手段を複数用意し、どれを使うかを判断にする。**選択肢に「怖いが上振れする馬」を
  必ず1頭混ぜる**（前作の1択支配の教訓）。
- **ビジネスマン**：C1は1鞍あたりの確率pで定義しろ。離脱は週数で持て。
  ⚠️離脱中に何も起きないと空白になる（前作の「何もしていない月」と同型）。
  C2の信頼値の閾値は⚠️前作が失敗した形（見えないので「気付いたら干されていた」になる）。
  ⚠️C3を入れるならC4を先に決めろ。第1弾では落馬と怪我だけにしろ。

### 5-2. 悪魔の代弁者による反論（6点）

1. **「断った馬が勝つ」は痛みではない。** プレイヤーはその馬に何も投資していない。失ったのは
   もらえたはずの利益であって、持っていたものではない。**持っていないものは奪えない。**
   前作が奪う器官を持てなかった真因はここ。
2. **落馬 p=0.04 は30年で当たり前になる。** 24鞍/年×30年＝720鞍。p=0.04なら生涯29回。
   **30年に伸ばした時点でレアイベントという概念が壊れている。** p=0.004にすると今度は
   最初の30分（24鞍）で一度も起きず、第3弾の通しプレイで体験できない。両立しない。
3. **数値を隠すと非支配性が測れない。** ロマンチストの案は§10・TODO #1の要求と衝突する。
   内部に数値があって表示しないだけなら測れるが、前作の`growthPow`情報漏洩バグと同型の
   事故（別の文言から等級が逆算できた）が待つ。**計測不能か情報漏洩かの二択。**
4. **C4を許すとC1〜C3が全部演出に落ちる。** localStorageセーブなら落馬した瞬間にリロードする。
   `sakurai-gameplay.md` #06「ズルを許せ」は**奪う器官が別にある場合の話**。
5. **「第1弾は落馬と怪我だけ」が最も危険。** 奪う対象が存在しない世界に怪我だけ置くと
   「進行が止まる罰」にしかならない。**奪う対象を先に作らなければ奪う機構は作れない。**
6. **オート消化が手動を上回る可能性が残っている。** 上回ったらプレイヤーは
   「自分がいない方が良かった」と知る。

### 5-3. アウフヘーベン——取り返しのつかないものは時間だけ

反論#1と#4は同じことを言っている。奪う対象が**取り返しのつく資源**だから起きる。
金は取り返せる。信頼値も取り返せる。怪我は治る。落馬はリロードで無かったことにできる。

**リロードして落馬を回避しても、その馬に乗れる年数は1週も増えない。**
馬は3歳でデビューし5〜6歳で引退する。乗れる期間は最初から決まっていて、どうやっても伸びない。

そこで奪う対象を「悪いことが起きる」から**「選ばなかった時間は二度と戻らない」**へ移す。

### 5-4. 中核の機構：主戦の座

- 馬には主戦騎手が1人だけいる。連続して乗ると主戦になる。
- **騎乗回数に応じて、その馬の能力が段階的に見えるようになる**（＝E2の解決）。

| 騎乗回数 | 見えるもの |
|---|---|
| 0回 | 血統表・前走成績・馬体重（誰でも見える公開情報） |
| 1回 | 前に行きたがるか、後ろで我慢できるか |
| 2回 | もっと長い距離が向くか、短い方が向くか |
| 4回 | 速さと粘りの段階 |
| 6回 | 気性（掛かるか、我慢できるか） |
| 8回 | この馬がどこまで上がれるか（底） |

⚠️この表の中身はE1（ユーザー執筆中）の結果で確定する。段数と回数だけが先に決まっている。

- **主戦の座は、乗らなかった週に失われる。** 落馬しなくても、怪我しなくてもいい。
  他の馬を選んだだけで失う。代わりに乗った騎手が勝てば乗り替わりが確定する。

### 5-5. 反論がどう解けたか

| 悪魔の指摘 | 解 |
|---|---|
| #1 持っていないものは奪えない | 主戦の座は持っている。6回乗って底が見えかけた馬。それを失う |
| #2 30年でレアイベントが壊れる | 奪うのは落馬ではなく毎週の選択。**層が違うので同じ数字で悩まなくてよい**（下表） |
| #3 数値を隠すと測れない | 内部に数値はある。**開示条件が「騎乗回数」という明示的なルール**なので逆算の余地がない。期待値は測れる |
| #4 リロードで無効化 | 主戦の座の喪失は確率イベントではなく**選択の結果**。リロードしても両方には乗れない |
| #5 順序が逆 | 第1弾で作るのは主戦の座。落馬と怪我はその上に載る増幅装置なので第2弾でよい |
| #6 オートが手動を上回る | 主戦の座は騎乗回数の蓄積。**オートに預けた鞍では積み上がらない**＝オートは主戦を作れない。構造的に上回れない |

### 5-6. 奪うことの3層構造

| 層 | 何が奪われるか | 頻度 | リロードで回避 | 最初の30分で体験するか |
|---|---|---|---|---|
| 毎週 | 選ばなかった馬に乗る機会 | 毎回 | **できない** | する |
| 数ヶ月 | 主戦の座（他騎手が勝った） | 年2〜3回 | 選択次第 | 1〜2回する |
| 数年 | 落馬による全ての主戦の座 | 30年で5〜8回 | できる | しない |

**最初の30分で体験するのは第1層。30年で効くのは第3層。** 層が違うので、1つの確率で
両方を満たす必要がなくなり、悪魔の指摘#2が解ける。落馬は **p=0.008/鞍**（30年720鞍で約6回）。
第3弾の通しプレイで落馬が起きなくてよい。

### 5-7. C2・C3・C4の確定形

- **C2**：信頼値の閾値を使わない。**主戦の馬が何頭いるか**で表現する。画面に
  「自分が主戦の馬」のリストが常にあり、減っていくのが見える。可視化の工夫が要らないのは
  **減っていく過程そのものが画面に出ている**から。⚠️前作の「気付いたら干されていた」が
  構造的に起きない。
- **C3**：主戦0頭が2年続くと引退勧告。A2の終わり方4通りの1つとして扱い、敗北とは呼ばない。
- **C4**：オートセーブ1スロットのみ。リロードによる落馬回避は明示的に許す
  （`sakurai-gameplay.md` #06）。**無効化されるのは第3層だけで、第1層と第2層は無効化できない**
  ので、奪う器官は生き残る。

## 6. オート消化（A2の一部）

### 6-1. 使える場所を限定する

⚠️オート消化の結果が手動と同じかそれより良ければ、**そのゲームは「あなたが操作していた時間に
意味はなかった」と自分で証明する。** 前作の「判断カードが実質1択」より直接的な失敗。

- **使えるのは引退を宣言した後だけ。** キャリア途中では使えない。
- 途中で使いたくなったら、それは**飛ばしたい区間の設計が悪いという報告**であり、
  機能ではなく計測結果として読む。

### 6-2. 構造的な保証

オートに預けた鞍は**騎乗回数に加算しない**。主戦の座は騎乗回数の蓄積なので、
**オートは主戦を作れない。** よってオートが手動を上回ることが構造的に起きない。

### 6-3. 副産物——判断カードのEV計測に使える

オート消化の計算は、B2で決めた「預けた鞍の自動処理」と同じもの。これを`tools/`のヘッドレス
simと同一の計算にしておけば、**「プレイヤーが乗った24鞍」と「オートが乗った24鞍」の差**が
そのまま取れる。TODO #1が要求する判断カードの非支配性計測が、ゲーム内機能の副産物として
手に入る。⚠️`decisioncard_ev.mjs`が現存しない（§0）ため設計から起こす必要があったが、

## 8. 難易度（H群・悪魔の釜）

`design/sakurai-gameplay.md` #05。⚠️**多くが見落とす2点**：
①上げるのに前払いのコストがかかる（パルテナではハート＝お金を釜に入れる）
②失敗すると賭けたものを失い、難易度が自動的に下がる（＝「イージーにしますか」の屈辱が無い）

**ユーザーの選択はH1＝ゲーム全体の難易度設定。** 上記2点が全体設定には素直に乗らないことを
提示した上で選ばれたため、そのまま進め、両方を持てる形を組んだ。

| 項目 | 決定 |
|---|---|
| 粒度 | ゲーム全体に1つ。**4段**（前作の`DIFFICULTIES`が4段で運用実績あり） |
| 効く対象 | **相手の強さ**。段を上げるほど同じレースに強い馬と騎手が集まる |
| リターン | 賞金・信頼・**騎乗回数の積み上がり**の3つに倍率 |
| 変更タイミング | **年の区切りで年1回**（30年で30回） |
| 前払いのコスト | 段を上げた瞬間から相手が強くなる。**リターンが返る前に勝てない期間を先に払う**。1年戻せない |
| 自動低下 | **主戦の馬が0頭の状態が1年続くと自動で1段下がる** |

### リターンに「騎乗回数の積み上がり」を入れた理由

この設計では主戦になるまで8回乗る必要があり、キャリアには30年という上限がある。
**一番貴重なものは金ではなく時間。** 高難度なら5回で主戦に届く形にすれば、リターンが
「もっと多くの馬と深く関われる」に変換され、構造に噛み合う。金額を増やすだけでは
前作の「使い道が枯渇」の再来になる。

### 自動低下の向きに注意（⚠️設計上の落とし穴）

パルテナの自動低下は**救済**。競馬で素直に作ると「依頼の質が下がる」＝弱い馬しか乗れない＝
さらに勝てない、と**悪化方向**になり符号が逆になる。
正しい形は「相手が弱くなる」であり、上表の通り**主戦0頭が1年でC3の引退勧告（2年）の手前**に
置く。すると引退させられる前に必ず1度、自動の救済が入り、プレイヤーが自分で
「イージーにする」を押す必要がない。

### 残った穴（H2で塞いだが記録しておく）

⚠️**勝てそうな時だけ段を上げ、危なくなったら下げる**——いつでも変更できるとこれが最適戦略に
なり、前払いのコストが払われない。パルテナがステージ単位で完結していたのはこれを防ぐため。
**年1回**に限定したことで塞いだ。⚠️今後「いつでも変更できるように」という要望が出たら、
この穴が再び開くことを先に伝えること。

### ⚠️却下した案

- **前作と同じ（main直下のindex.htmlをコミット）**：設定作業ゼロだが、1.4MB差分と

## 13-1. C2：信頼値を復活させる（私の説明が不正確だった）

§5-1でビジネスマンが述べた「信頼値の閾値は前作が失敗した形」を、私はそのまま
「信頼値の閾値は使わない」と結論に書いた。⚠️**これは区別の失敗である。**

**反対すべきだったのは信頼値そのものではなく、「不可視のまま干す判定に使うこと」だった。**
前作の失敗は閾値が悪かったのではなく、プレイヤーから見えないところで数字が動いて
気付いたら手遅れだったこと。**見えるなら閾値で問題ない。**

さらにユーザーの案のほうが構造的に強い——**「悪事に手を染めると金は入るが信頼が極めて下がる」**。
これは悪魔の釜そのもので、リスクとリターンが同じ選択の中にあり、しかも
**リターンが即座に、リスクが遅れて来る**。H群の全体難易度設定より釜として正しく機能する。

**確定形**：

- **信頼は「人」に対して持つ**（調教師・馬主ごと）。**主戦の座は「馬」に対して持つ**。別物なので両方持つ
- **信頼が下がると、その人の厩舎の馬の依頼が来なくなる**＝そこで主戦だった馬を**まとめて失う**
- つまり信頼値は、主戦の座を一気に奪う**増幅装置**（落馬と同じ位置）
- ⚠️**信頼値は必ず画面に出す。** 見えない閾値で干すことだけは禁止
- ⚠️**信頼値は時間で回復できる**ので、それ単体では奪う器官として弱い。
  **奪う器官の主役は引き続き主戦の座**（取り返しのつかない時間）。信頼値は
  「依頼の質と量を決める入力」という役割に留める

## 13-2. B2・§6-2の訂正：預けた鞍も騎乗回数に加算する

⚠️**§6-2の「オートに預けた鞍は騎乗回数に加算しない」は誤りだった。**

預けた鞍でも**騎手本人は乗っている**。プレイヤーが操作しなかっただけである。
乗ったのにその馬を知らないままなのは筋が通らない。

このルールを置いた理由は「オートが手動を上回らないようにする」ためだったが、
**2つの別物を混同していた**：

| | 何か | 主戦の座への影響 |
|---|---|---|
| **預ける** | キャリア途中。その鞍が自動で処理される | **加算する**（乗っているので） |
| **オート消化** | 引退宣言後のエピローグ | 引退後なので、そもそも何も積み上がらない |

**正しい形**：預けた鞍も騎乗回数に加算する。ただし**判断カードが無いぶん着順が悪くなり、
勝てなければ主戦の座は守れない。** オートが手動を上回らないことはこれで十分に保証される。

**年間騎乗数**（⚠️旧設計の年40鞍は実在のJRAの最下位クラスの数字だった）：

| 段階 | 年間騎乗数 |
|---|---|
| 新人（デビュー1〜3年） | 80鞍 |
| 中堅 | 250鞍 |
| 一線級 | 500鞍 |
| トップ（リーディング上位） | 800鞍 |

**騎乗数そのものが地位の指標になる。** 800鞍でも主戦は増えすぎない——主戦は
**同じ馬に8回**乗る必要があり、大半の馬は1〜2回の単発だから（実在の騎手の主戦も10〜20頭）。
人為的な上限は要らない。

プレイヤーが自分で操作するのは**年8鞍程度**（§2の判断予算から）。判断の中身は
**「どの馬に鞍数を投資するか」**。

⚠️**本物の制約が1つ生まれる：同じレースに2頭は乗れない。** 主戦の馬AとBが同じレースに
出るとき、必ずどちらかを捨てる。**ここが第2層（主戦の座を失う）の最も自然な発火点になる。**

## 13-3. E2：段階開示から確率開示へ

### 旧設計の欠陥

騎乗回数 0/1/2/4/6/8 の固定ラダーは、**3回目・5回目・7回目に何も起きない**。
その回に乗っても何も分からず、投資した1鞍が空振りになる。
「もう1回乗れば」で引っ張る設計なのに、**3回に1回は必ず裏切る作りだった。**

さらに**主戦の座（8回）と完全な理解（8回）が一致してしまい、8回目で「この馬は終わった」**に
なっていた。

### 確定形（確率開示）

開く項目は全**8つ**：脚質／適距離／スピード／瞬発力／勝負根性／賢さ／健康／底。

- **1回目は確率1.0で必ず1つ開く**（脚質 か 適距離のどちらかがランダムに）。
  ⚠️初めて乗った鞍が空振りだと最悪なので、ここだけ保証する
- **2回目以降は毎回1判定。成功したら未開示の項目から1つがランダムに開く**
- 確率 **p = 0.55 ＋ 0.15 ×（連続で開かなかった回数）**。開いたらリセット、**上限0.95**
  → 2回連続の空振りは起きるが、3回連続はほぼ起きない（⚠️天井が無いと空振りの尾が長く伸びる）
- 実効確率は約0.65。**8回時点で開いているのは平均5.5項目。全8項目に届くのは12回前後**

### この選択の帰結（旧設計より良くなった点）

**主戦の座（8回）と、馬を知り切ること（12回前後）がずれる。**
主戦になっても、その馬をまだ知り切っていない。**乗り続ける理由が8回で終わらない。**
固定ラダーではここが一致していたため、8回目で馬への興味が切れていた。

### ⚠️ 受け入れたリスク（ユーザーが承知の上で選択）

**賢さは判断カードの効き幅を決める軸**であり、他の軸とは重さが違う。
確率開示では、**運が悪いと7鞍投資しても「自分の判断がこの馬に通るのか」が分からないまま**になる。
これは「分散だけあって判断が無い」状態に近づく方向であり、選択肢の説明でその旨を提示した上で
ユーザーが選択した。⚠️**§10の計測で実際にどの程度起きるかを必ず測ること。**

## 13-6. Q1：年に何鞍操作するか（総プレイ時間を確定）

⚠️**年8鞍という数字は、私が総プレイ時間を一度も確認しないまま置いた仮定だった。**
キャリア年数は確認したが、30年フルプレイの目標時間は「30分＝最初の部分」しか決めておらず、
そこから逆算された年8鞍が独り歩きしていた。

年8鞍で計算すると **0.16鞍/週＝6.25週に1回**。止まる週も年6〜8回なので、実質
**「年7ターンのゲーム」**であり、⚠️週次で進むと決めた意味が薄れていた。
さらに**主戦の座（同じ馬に8回）に1頭あたり8年かかり、仕組みが事実上成立していなかった。**

**確定：総プレイ時間20時間・年33鞍操作・1.5週に1回。**

| | 値 |
|---|---|
| 総プレイ時間 | 20時間＝72,000秒 |
| 操作する鞍 | 年33鞍 × 30年＝**990鞍** |
| 判断の総数 | 990鞍×3（騎乗前1＋カード2）＋その他約1,000＝**約4,000** |
| 1判断あたり | 18秒 |
| **最初の30分** | 100判断＝約33鞍＝**デビューから1年目の終わりまで** |

**帰結**：

- **第3弾で人間が通すのは「デビュー〜1年目」**（旧設計では3年分だった）。1シーズンを丸ごと
  1回通すほうが検証としてまとまっている
- **主戦の座が現実的な速度になった。** 1頭に集中すれば1年以内、並行なら1〜2年で8回に届く
- ⚠️**使い道の枯渇リスクが最大になった。** 20時間・年33鞍・30年ぶんの使い道が要る。
  前作は13.7年で枯渇した。**第1弾-Bの最重要項目**
- 操作鞍数は地位で変動させてよい（新人20→トップ45で平均33）。名目の騎乗数が新人80鞍なので、
  新人期は4割を自分で操作し、トップになるほど大半を預ける形になる。
  **地位が上がるほど日常が委任に変わるのは実態にも合う**

## 13-7. Q2・Q3：操作対象の決め方と、新しい馬との出会い

⚠️**どちらもユーザーの指摘を受けるまで未設計だった。** 特にQ3は、
**主戦の座を「奪う」仕組みだけ作って「得る」仕組みを作っていなかった**＝奪われる一方の
ゲームになる、という重大な欠落だった。

### Q2：馬単位で宣言する

**鞍ごとに選ぶのではなく、「この馬は自分で乗る」と馬単位で宣言する。**
宣言した馬が出るレースは自動的に操作対象になり、それ以外は全部預ける。

⚠️800鞍から8鞍を選ぶリスト操作は成立しない（800件は出せない）。馬単位なら成立する。

**宣言枠に人為的な上限は置かない。** 年33鞍という時間の制約が自然に上限を作る——
馬は年6〜8回走るので、宣言できるのは**4〜5頭**。これがそのまま「主戦にできる馬の数」になる。

これによりQ2の判断が「どの馬に鞍数を投資するか」＝主戦の座の判断と**同一のものになる**。
判断が2種類に分かれず1本に収まる。

### Q3：調教騎乗を入口にする

1. 信頼の高い調教師の厩舎に出入りできる
2. **朝の調教でその厩舎の若い馬に乗る**（調教騎乗も騎乗回数に加算する。レースより軽い扱いでもよい）
3. 「これは走る」と分かった馬のデビュー戦の騎乗を頼む
4. 乗り続けて主戦になる

これで **信頼 → 出会い → 主戦の座 → （失う）** が一本の環になる。
§13-1で信頼値に与えた「依頼の質と量を決める入力」という役割が、そのまま出会いの蛇口になる。

⚠️**悪事で信頼を失うと、今持っている馬だけでなく未来の馬も失う。**
奪う器官がここで一段深くなる。

## 13-8. B4：必ず知らせるものだけ先に決める

⚠️当初B4を「UIだから後回し」と分類したのは誤り。CLAUDE.md §10が警告する
「UIだと思っていたら数値が動いていた」型に入りかけていた。特に危なかったのは、
**第2層（他騎手が勝って乗り替わりが確定する）が飛んだ週の中で起きる**ため、
飛ばし方が雑だと**主戦の座を失ったことに気付かない**という点。C2で防いだのは
「信頼値が見えないこと」だけで、この穴は別に開いていた。

正しい切り分け：

| | いつ決めるか |
|---|---|
| **飛んだ週に何が起きうるか。何を必ず知らせるか** | **今決める**（設計であって§8の対象外） |
| その情報をどう見せるか（レイアウト・級数・配置） | §8の手順（候補を複数提示→選択→合意→実装） |

**必ず知らせる5項目（確定）**：

1. **主戦の座を失ったこと**（最優先。これを見落とさせない）
2. 預けた鞍で自分の馬が勝ったこと
3. 怪我と落馬
4. 信頼が大きく動いたこと
5. 新しい依頼が来たこと

**知らせないもの**：単に鞍数をこなしただけの週。

なお13-6で1.5週に1回止まる形になったため、飛ぶのは**年17週**だけになり、
B4は体験の大半を占める問題ではなくなった（年8鞍時代は年42週が飛んでいた）。
