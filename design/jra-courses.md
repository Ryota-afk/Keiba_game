## 3. 起伏（高低差の位置。レースの前半・後半のペースに関わる点）

| 競馬場 | 芝の起伏（J1の本文） | 直線の坂 |
|---|---|---|
| 札幌 | ほぼ平坦（J1札） | 無し |
| 函館 | ゴールから2コーナーへ下り、そこから4コーナーまでだらだらと上り、直線へ向けて下る。3〜4コーナーが小高い丘（J1函） | 無し（直線は下り） |
| 福島 | ゴールから2コーナーまで下り（1.7m）、向正面に上り（1.3m）、4コーナーから直線へ下り、**残り170m〜50mに上り（1.2m）**（J1福） | あり（ゴール前に1.2m） |
| 新潟 | 内回り・ダートはほぼ平坦。外回りは3・4コーナーに下り（1.6m）（J1新） | 無し |
| 東京 | 1コーナー〜向正面半ばに下り（1.9m）、3コーナー手前に上り（1.5m）、4コーナー手前からまた上り気味。**直線の残り460m〜300mに上り（高低差2m）**、上り切ってからゴールまで約300m（J1東）。J4（ダービー等）は「全長160m・高低差2m」 | あり |
| 中山 | ゴールから1コーナー上り、2コーナー手前が最高点、その後ホームストレッチ半ばまで下り。**残り180m〜70mに急坂（高低差2.2m、最大勾配2.24%でJRA最大）**（J1中山） | あり（急坂） |
| 中京 | ゴールからなだらかに上り向正面半ばで最高、直線入口へ下る。**直線に入ってすぐに高低差約2mの坂（約2%）**、その後ゴールまで200m余り（J1中京） | あり |
| 京都 | 起伏は**3コーナーの丘だけ**。向正面半ばから3コーナーへ上り、4コーナーで一気に下る。直線は平坦（J1京）。J4マイルCS「残り820m付近から急な下り」「高低差3.9m」 | 無し |
| 阪神 | 内回りは残り800m、外回りは残り600mから直線半ばまで緩い下り、**ゴール前に急坂（高低差1.8m、勾配1.5%）**（J1阪） | あり |
| 小倉 | ゴールから2コーナーまで緩く上り、2コーナーから向正面・3〜4コーナーを下る。直線は平坦（J1小）。2コーナーが最高所（J5 小倉2026-01-24「2コーナー付近が勾配の頂点」） | 無し |

ダート：東京と中山は芝と同じ起伏で直線に坂（東京は高低差2.4m、J1東本文。表は2.5m。中山は芝と同様の急坂）。阪神は残り200m付近に高低差1.6mの坂（J1阪）。京都は3コーナーに丘、直線は平坦（J1京）。中京は芝と似た起伏（J1中京）。小倉は残り400mから直線にかけて緩い上り（0.6m。J1小）。福島は芝とほぼ同じ起伏（J1福）。

## 5. 仮柵（A・B・C・Dコース）

### 5-1. 何のためか
- 芝コースで内側の柵（内ラチ）を外へ動かし、内側の芝が痛みすぎるのを防ぐ。JRA用語辞典「仮柵」：「内ラチから5メートル、10メートルなど一定の距離に柵を設けることによって、内側の芝の過度の消耗を防ぐ」（J8 `w400.html`）。
- 定義：「最内柵による馬場をAコース、Aコースの外側に設定した馬場を、内側から順次Bコース、Cコース、Dコースという」（J2）。
- 東京・京都が4コース（A〜D）、他場はA〜B、またはA〜C（J1京）。広い幅員を生かして使い分けて傷みを分散（J1東・J1小）。
- 今は「仮柵」ではなく「移動柵」で、すべての競馬場で採用。距離の差は発走地点を動かして調整するため同じ距離表記のまま。仮柵と呼ばれていた頃は発走地点が一定だった（W競。JRA側で同じ記述は見つけていない）。

### 5-5. コースを替えると距離はどうなるか
- 周長が増える（例：東京 A 2,083.1→D 2,139.6m。J1東。京都 内 1,782.8→1,839.9m。J1京）。直線はわずかに短くなる（京都 A 328.4→B 323.4m）か、増える（札幌 266.1→269.1m、函館C 264.5m）。
- 距離表記はコースを替えても同じ。最初のコーナーまでの距離がコースごとに変わる（中山芝2000：A 404.9m→C 367.2m。京都芝2000：A 308.7m→D 246.7m。J4）。
- 出走可能頭数もコースで変わる（たとえば新潟芝直線1,000mはAコース18頭、Bコース16頭。J2）。

## 6. 斜行の制裁

### 6-1. 何が禁止されているか
- 「騎手は、競走中みだりに斜行し、又はだ行してはならない」（施行規程第112条第2項。J7）。同条は他に「2馬身以上の距離がないのに後続馬の進路に入らない」「直線で一度定めた進路をみだりに変えない」「他の馬を押圧・衝突しない」「十分な間隔がないのに他の馬の間に入らない」を禁じる。
- 用語辞典「斜行」：競走中、馬が斜めに走ること。騎手が注意義務を怠ったと認められ、他馬の走行に影響を及ぼした場合は制裁（J8 `w250.html`）。

### 6-2. 制裁の種類（規程第137条・第147条。J7）
1. **騎乗停止**（調教師は調教停止）
2. **過怠金**（上限は第147条で1,000,000円以下）
3. **戒告**（用語辞典：公正かつ安全な競馬に対する注意義務を怠った騎手または調教師に科せられる制裁。J8 `c10130_list.html`）
4. 競馬関与の禁止・停止（斜行ではなく不正等の重い事案。第138条）

第147条第7号に「第112条の規定に違反した調教師もしくは騎手」があり、斜行は第147条（期間を定めた騎乗停止・戒告・過怠金のいずれか）の対象。
外国の競走での違反は第147条第18号（「外国の競馬の競走の公正かつ安全な実施を害する行為をした者」。J7）が対象で、現地で受けた制裁を考慮する書きぶり（現地で既に騎乗停止の期間を満了したと認められる者は除く）。

### 6-3. 騎乗停止の日数の決まり
- **何日・何週の標準量定表は、承認済みの出典では見つからなかった。**
- 規程にある決まり：開催中の事由に関する**30日以内**の騎乗停止・過怠金・戒告は**裁決委員**が行い、**30日を超える停止**は**裁定委員会**が行う（第148条。J7）。
- 実例：2020年の中京の斜行（決勝線手前で外へ斜行し、他馬の進路を狭めた）に対し、騎手は短期間に同様の不注意騎乗を繰り返したことを考慮され、「2020年10月3日（土）から10月11日（日）まで**9日間（開催日4日間を含む）**の騎乗停止」（J9）。期間は暦日で書かれ、開催日の数が括弧で併記される。**繰り返しで重くなる**ことが分かる。
- 実例（地方競馬での斜行をJRAが相互適用した分）：「最後の直線で外側に斜行し他馬の走行を妨害」→平成16年9月4日〜9月19日の騎乗停止（16日間）。「第3隅角で内側に斜行し他馬の進路に影響を与えた」→10月2日〜10月3日の騎乗停止（2日間）（J10）。同じ「斜行」でも、妨害か影響かで日数が大きく違う。
- 過怠金の実例：施行規程の上限しか確認できず、斜行に対する過怠金の金額の実例（JRAの個別処分ページ）は、ページがアクセス不可だったため確認できなかった。

### 6-4. 着順への措置（降着・失格）
制裁（騎手）と着順の変更は**別々に判断する**。降着にならなくても騎乗停止はありうる（J8 `judge/` のQ&A「着順が変わらなくても騎乗停止などのペナルティーを科すことがあります」）。

| 措置 | 条件 | 出典 |
|---|---|---|
| **降着** | 加害馬の有責妨害（第112条第1・4・5項または第113条第1項の違反）があり、**その妨害がなければ被害馬が加害馬より先に決勝線へ到達していた**と裁決委員が認めたとき。加害馬は被害馬の**すぐ後ろの着順**になる。ただし被害馬も加害馬に有責妨害をしていた場合は降着にしないことができる。判断は着順・着差だけでなく被害の程度・場所・前後の走行状況を総合して行う | J7第124条、J8 `judge/`・`w238.html` |
| **失格** | 有責妨害のうち、**極めて悪質で、他の騎手や馬に対する危険な行為**であって、競走に重大な支障を生じさせたとき | J7第123条第4号、J8 `judge/` |
| 落馬した被害馬 | 被害馬が落馬・競走を中止しても、失格にあたらない限り**着順は到達順位のとおり**。必ずしも失格にならない | J8 `judge/` |
| 審議の表示 | 5位以内に入線した馬で着順変更の可能性があるとき、審議ランプが点灯 | J8 `judge/` |
| 事後失格 | 競走の翌日から5年以内に、禁止薬物の使用・馬の全能力の不発揮・不正協定が確認された場合 | J8 `kakutei.html` |
| 不服申立て | 失格・降着の裁決などに、馬主・調教師・騎手が不服を申し立てられる。裁定で着順が変わっても払戻しの勝馬は変わらない | J8 `kakutei.html` |

降着制度は1991年に導入、2013年から現行の基準（到達順位を重んじる方式）に変更（J8 `kakutei.html`「2013年から降着・失格のルールが変わりました」、同ページ。1991年はJRAページを検索した要約で、本文では未確認）。

#### 騎乗停止の日数の数え方

- JRAの裁決レポートの書式は**「◯◯日間（開催日◯日間を含む）の騎乗停止」**で、◯◯日間は**始期から終期までの暦日**、括弧は**その間にある開催日の数**（J3・J5・J6・J7・J9・J10）。開催日2日のときは括弧を付けず「2日間」とだけ書く（J4・J8・J9。期間は土曜〜日曜の連続2日）。J1・J2（2018・2019年）は「9日間」だけで括弧が無い（同じ9日でも書式が今と違う。J1は4/21の土曜〜4/29の日曜）。
- **日数を暦日で数えるか開催日で数えるかを定めた条文は、見つからなかった**（J7＝施行規程第137条・第147条・第148条は制裁の種類・上限・誰が決めるかのみ）。実質的な数え方はW2に「競走中の事由による騎乗停止は開催日4日間などの騎乗停止となり、土・日〜（翌週）土・日の期間が騎乗停止になるため、実質的に1週間は中央・地方・日本国外全ての競走に騎乗できない」とある。
- 始期：W2によると、1976年までは次の競走から即時、1977年以降は翌日から、1994年からは翌週の土曜日から、**2020年から「審査対象の競走から数えて2週間後の最初の開催日」**。実例でも合う：2025-03-15/16の事案→3/29から（J7）、2026-06-28→7/11から（J9）、2026-11-23→12/5から（J10）。
- 外国・地方の処分は**現地の暦日の期日をそのままJRAも適用する**（J15〜J17）。中央・地方の相互適用は「主催者ごとに開催日数が違うため、要因が同じでも期間が異なる場合がある」（W2）。
