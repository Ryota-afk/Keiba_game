# JRAの出走馬の決め方（収得賞金・出走馬決定賞金・優先出走権）

出典：JRA公式（2026-09-10取得・Shift_JISの本文を直接読んだ）
- 競馬用語辞典「収得賞金」`jra.go.jp/kouza/yougo/w541.html`
- 「出走馬決定順一覧（特別登録）の見方」`jra.go.jp/keiba/tokubetsu/mikata.html`
⚠️どちらも**現行制度**。1974年当時の算入額・優先出走権の制度は未確認（当時の頭数上限も違う。
1974年の結果表ではオークス26頭・桜花賞25頭・ダービー23頭＝`devlog/wave06.md`）。

## 1. 収得賞金（用語辞典の原文の要点）

「競走条件（クラス）を区分するための賞金のこと。中央競馬のレースの場合、レースで第1着
（**重賞競走は2着まで**）となったときに、出走したレースの競走条件に応じて下表の金額が算入される。」

| 競走 | 算入額 |
|---|---|
| 新馬・未勝利 | 400万円 |
| 1勝クラス | 500万円 |
| 2勝クラス | 600万円 |
| 3勝クラス | 900万円 |
| オープン（重賞を除く）2歳・リステッド | 800万円（九州産馬限定500／上記以外600） |
| オープン（重賞を除く）3歳・リステッド | 1,200万円（上記以外1,000） |
| オープン（重賞を除く）3（4）歳以上・リステッド | 1,400万円（上記以外1,200） |
| 障害 一般／特別 | 600万円／750万円 |
| **重賞** 3歳・3（4）歳以上、2歳GⅠ・GⅡ | **該当する着順の本賞金額の半額**（1着・2着） |
| 重賞 2歳（GⅠ・GⅡ以外） | 1着1,600万円・2着600万円 |

## 2. 出走馬の決め方（「見方」の原文の要点）

- 「レースへの出馬投票頭数が出走可能頭数を超過した場合は、以下の場合を除き、一覧に記載されて
  いる馬の上から順に出走できる馬となります」＝**出走馬決定賞金の多い順**。
- **出走馬決定賞金**（古馬オープン）＝①通算収得賞金 ＋ ②概ね過去1年の収得賞金 ＋ ③概ね過去2年の
  GⅠ・J・GⅠの収得賞金（地方・外国を含む）。「詳細な算出対象期間は、開催ごとの競馬番組にて定めて
  おります」。
- 春の3歳GⅠ：芝のオープン競走・1勝クラス・パートⅠ国の収得賞金が対象。
- **上位クラスの馬が優先**：「3勝クラスの馬が同じレースに特別登録したオープン馬の出走馬決定賞金を
  上回った場合でも、出走馬決定順はオープン馬が上位となります」。
- **優先出走権**（順位が下でも出走できる）：
  - ファン投票：出馬投票した馬のうちファン投票上位10頭（順位50位以内に限る）
  - レーティング：古馬GⅠ（宝塚記念・有馬記念を除く）で、出馬投票した馬のうち上位10頭
    （レーティング110・牝馬106未満は対象外）
  - GⅠ等優先：トライアル・前哨戦で優先出走権を得た馬
  - ［地］ステップ／［地］成績：地方馬
  - 外国馬：優先して出走できる
- 同一順位は抽選（ファン投票の注記）。

## 3. このゲームでの使い方（決めた設定は`devlog/wave06.md`に記録）

- 馬に**収得賞金**の欄を持たせ、上の表の額で積む（架空馬）。
- 重賞の枠（18頭）は**通算収得賞金の多い順**で決める（本筋2では②③の期間合算は作らない）。
  ⚠️クラスは正本どおり**勝利数**で上げる（`arch/horse.md`「クラスの昇降」・`nextClassAfterRace`）。
  収得賞金の欄は重賞の枠の順位にだけ使う。「上位クラス優先」は作らない（架空馬の候補は
  オープン馬に限るので効かない。決定3で変わりうる）。
- 史実馬の収得賞金＝重賞の1着・2着の算入分＋仮置き額2,400万円（上4段の合計・全頭一律）。
  史実馬どうしの同額は**結果表の着順が上の馬を残す**（2026-09-10ユーザー決定(c)。着順の使い方は
  出走18頭の選定まで。レースの結果には使わない）。架空馬が絡む同額は種付き乱数の抽選。
- 優先出走権は本筋2では作らない（`TODO.md`#69）。
