## 1. 毛色

### 1.1 種類は8つ（確認済み）

> サラブレッドの毛色は、8種（栗毛、栃栗毛、鹿毛、黒鹿毛、青鹿毛、青毛、芦毛、白毛）と決められている。
> 白毛は非常に珍しく、日本には数頭しかいない。（J用語「毛色」）

Wikipedia（W毛色「競走馬の毛色」）も同じ8種で、「駁毛や駁鹿毛といった登録区分はないため、定義に当てはまる
8種類のいずれかに分類される」。登録はジャパン・スタッドブック・インターナショナル（JAIRS）が血統登録の審査で判定する（J優駿37）。

各毛色の定義（J毛色の本文。JRAが挙げる代表馬も併記）：

| 毛色 | JRAの定義（原文） | JRAの代表馬 |
|---|---|---|
| 鹿毛 | 被毛は明るい赤褐色から暗い赤褐色までありますが、長毛と四肢の下部は黒色です。栗毛との違いは長毛と四肢の下部の色で、栗毛は黒くなりません。 | ディープインパクト、ウオッカ、キタサンブラック 他 |
| 黒鹿毛 | 被毛の色合いが黒味がかった赤褐色で…眼の周辺、腋、ひばら、下腹及び内股は褐色で、長毛と四肢の下部の色は…黒色です。 | ナリタブライアン、スペシャルウィーク、ブエナビスタ 他 |
| 青鹿毛 | 全身ほとんど黒色で眼及び鼻の周辺、腋、ひばら等がわずかに褐色です。 | メジロラモーヌ、マンハッタンカフェ 他 |
| 青毛 | 被毛、長毛共に黒色です。軽種馬には比較的少ないです。…季節により、毛の先が褐色となり黒鹿毛や青鹿毛のように見えることがあります。 | シーザリオ、ヴィルシーナ、ヴィブロス |
| 芦毛 | 原毛色は栗色、鹿毛、青毛等ですが、被毛全体に白色毛が混生し、年齢が進むにつれて白色の度合いが強くなり純白になります。 | タマモクロス、オグリキャップ、メジロマックイーン、ゴールドシップ 他 |
| 栗毛 | 被毛は黄褐色で、長毛は被毛より濃いものから淡く白色に近いものまであります。 | タイキシャトル、グラスワンダー、オルフェーヴル 他 |
| 栃栗毛 | 被毛は黒味がかった黄褐色から黒味の非常に濃いものまでありますが、黒色にはなりません。 | サッカーボーイ、サクラローレル、マーベラスサンデー 他 |
| 白毛 | …白色または全身の大半が白色で生まれますが、眼には色素があり…いわゆるアルビノではありません。芦毛との違いは、生時に既に大半が白色を呈していることです。 | ユキチャン、ブチコ |

補足（確認済み）：
- **芦毛は年齢で白くなる**。J用語「芦毛」：「出生時は原毛色にわずかに白色毛を混生する程度…その進度は個体によりまちまちで、
  その色合いも純白になるものから原毛色をわずかに残したままのものまである」。W芦毛にオグリキャップの写真説明
  「1994年撮影。9歳。まだ黒い部分が残っている」「2008年撮影。23歳。加齢によりほぼ白化した」。
- **尾花栗毛**は毛色の区分ではなく、栗毛のうちたてがみ・尾が白っぽいものの呼び名（J用語「尾花栗毛」、J優駿35のトーホウジャッカルの写真説明）。
- **白毛でも全身真っ白とは限らない**。JAIRSの定義は「わずかに有色の斑紋および長毛を有するものもある」。日本最初の白毛馬
  ハクタイユー（1979年登録・W白毛）にも大きな茶色の斑があった（J優駿38）。
- **黒鹿毛と青鹿毛は見分けにくい**（W黒鹿毛「青鹿毛との区別は比較的難しく、区別しない言語も多い」）。

### 1.3 遺伝（確認済み）

J優駿36（楠瀬良・日本装削蹄協会）の表。栗毛には栃栗毛、鹿毛には黒鹿毛・青鹿毛を含めて説明している：

| 遺伝子型 | 毛色 |
|---|---|
| AAee・Aaee・aaee | 栗毛（栃栗毛を含む） |
| aaEE・aaEe | 青毛 |
| AAEE・AAEe・AaEE・AaEe | 鹿毛（黒鹿毛、青鹿毛を含む） |

- **栗毛の法則**：「栗毛（栃栗毛も含む）の両親からは、栗毛の子どもしか生まれない」（J優駿35）。
- **芦毛の法則**：「芦毛馬の両親のどちらか一方は必ず芦毛でなければならない」「Ｇがあればそれとは関係なく芦毛になって
  しまう」（J優駿36）。W芦毛も同じ（芦毛遺伝子は白毛・佐目毛を除く全ての毛色遺伝子に顕性）。例外は白毛の親が芦毛の
  遺伝子を隠し持つ場合（W芦毛：白毛のマシュマロが、両親とも芦毛でない芦毛の子を産んだ例）。
- **白毛**：優性の白毛遺伝子Wを片親から受け継ぐと白毛。Wは他の全ての毛色遺伝子の働きを抑える。「【ＷＷ】は致死」
  （J優駿37）。⚠️W白毛は「ホモで持つと発生段階で死亡すると言われているが、これを否定する研究もある」（W毛色）。
  突然変異でも生まれる（W白毛：日本ではハクタイユーが最初）。
- 黒鹿毛と鹿毛を分ける遺伝の違いは分かっていない（W鹿毛・W黒鹿毛）。栃栗毛と栗毛の差も分かっていない（W栗毛）。
- **手元のデータで確かめた**：§1.2(c)の415頭のうち両親とも栗毛系の21頭は全て栗毛系。芦毛の24頭は全て片親が芦毛。
  片親が芦毛の45頭のうち芦毛は24頭（53%。片親がヘテロなら理論上1/2）。例外0件。

### 1.4 毛色と能力（確認済み）

- J研76：「芦毛（白毛含む）は、栗毛（栃栗毛含む）、黒鹿毛（青毛、青鹿毛含む）、鹿毛と比較して複勝率に差が見られなかった。
  また、熱中症の発症率も毛色により差がないことが分かっている」。§1.2(a)の勝率・複勝率もほぼ同じ。
- J優駿37：白毛の活躍馬が少ないのは「競走能力とはまったく関係がありません…個体数が極めて少ないというだけのこと」。

## 2. 白斑（白い模様）

### 2.1 名前（確認済み）

Wマーキング（日本軽種馬登録協会『馬の毛色と特徴』を参考文献に挙げる）の定義を要約。顔：

| 名前 | 場所・形 |
|---|---|
| 星（ほし） | 額の白斑。親指より小さければ**小星**、握り拳より大きければ**大星** |
| 曲星・乱星・環星 | 曲がった星・形の乱れた星・環状の星 |
| 流星（りゅうせい） | 星が鼻筋の方向へ流れているもの。大流星・小流星・曲流星・乱流星 |
| 鼻梁白（びりょうはく） | 鼻筋の縦長の白斑。鼻梁大白・鼻梁小白 |
| 鼻白（びはく） | 鼻の白斑。鼻大白・鼻小白 |
| 唇白（しんはく） | 唇の白斑。上唇白・下唇白 |
| 作（さく） | 額から鼻まで続き、幅が鼻骨とおおむね同じでまっすぐなもの。大作・細作 |
| 白面（はくめん） | 額から鼻まで続き、顔の半分以上または両目の幅に及ぶもの |

脚（白斑の高さと形で分ける。下から）：微白・小白・半白・白・細長白・長半白・長白。
「白」は「短い靴下をはいているかのよう」、「長白」は「長靴下をはいているかのよう」。

JRAの子ども向け資料（JRA『ウマミニ百科』`https://www.jra.go.jp/ebook/umamini/pageindices/index16.html`）は
星・白面・作・曲星だけを挙げ、「まるで肢に白いソックスをはいているようなウマがいます」と書く。

### 2.2 書き方（確認済み）

顔の白斑は組み合わせて1語で書き、脚は「左前肢半白」のように脚の位置を前に付ける。実例（W馬の情報欄「斑」）：
- テンポイント：「流星鼻梁鼻白」「左前肢半白」（W馬）
- トウショウボーイ：「右後小白」
- フランケル：「星」「四白」（⚠️「四白」は4本の脚が白いことの通称。Wマーキングの定義表には無い）

Wマーキングの図の説明には「大流星鼻梁白鼻白」「流星断鼻梁鼻白」「流星鼻梁小白」などの組み合わせが並ぶ。

### 2.3 一生変わらない（確認済み）

「マーキングは出生時には既に存在して、一生変わることがない」（Wマーキング）。血統登録では顔・脚の白斑と旋毛（つむじ）を
照合して本人確認に使う（ウマミニ百科・J優駿37）。

### 2.4 頻度：**出典なし**

承認済みの出典に、白斑の種類ごとの割合を書いたものは見つからなかった。
- JRAの成績PDF（J成績2024）・G1成績ページ・優駿達の蹄跡の馬のページには**白斑の欄が無い**。
- Wikipediaの競走馬の情報欄には「斑」の欄があるが、本文に「馬のマーキング」を含む競走馬の記事130本
  （「競走馬」の情報欄を持つ記事は5,919本）を取ったところ、**「斑」が書かれていたのは5本だけ**（上の3頭とサトノダイヤモンド・
  バラエティクラブ。後の2頭は欄が空）。
- ⚠️したがって**割合を数字で決めるなら根拠は無い**。「たいていの馬は何かしら白斑を持つ」はWマーキングに
  「大部分の馬はいくつかのマーキングを持ち」とある（出典の数字は無い）。

## 3. 馬体重

### 3.1 発表のされ方（確認済み）

- 当日の馬体重は「発走時刻の概ね70分前に計量」（J調教後）。大きなレースでは3〜4日前の「調教後の馬体重」も発表される
  （J調教後・Jブログ輸送）。
- 成績表の「前走との増減」（J見方）：「原則として前回出走時の馬体重量との増減を表示しています。…前回出走時の馬体重が
  不明な場合は空欄…初出走馬は、－で表示」。前走が海外でも計量していれば比べる（J調教後）。
- 表記：JRAの成績PDFは「472＋6」「524± 0」「488 ―」（初出走）。G1成績ページは2023年が「478 (0)」、2001年が
  「504Kg +10」。

### 3.4 なぜ変わるか（確認済み）

- 「健康な時でも一日に10kg以上も変わることがある…1〜2分間強い運動を行った場合で約1ℓ（1kg）、1時間の運動で約11ℓ（11kg）
  の発汗…1回の排糞や排尿で2kg以上減ったりもします」（Jブログ輸送）。
- 「馬体重は、『調教』・『輸送』・『飼付』・『排糞』等により、常に大きく変動します」（J調教後）。
- 暑い中で激しく運動した後は「体重は6-7kg減少する」（J研76）。
- **季節**：「オスでは1月に最も重くなり、8月に最も軽くなっていたが、メスでは、10月に重くなり、3月に軽くなっていた」
  「セン馬では…11月に重くなり、7月に軽くなっていた」（J研71）。2024年の4歳以上の牡の月平均も7月485.3kgが最も軽く
  12月493.7kgが最も重い（自分で集計。年の途中で馬齢が変わる影響を除いていない）。
- **成長**：4歳の夏〜秋まで増え、その後ほぼ一定（J研71）。走る速さのピークも4歳秋（J研70）。

### 3.5 体重と成績の関係

**体重そのもの（確認済み・JRAの研究）**：
- 「牡牝とも出走時体重が上位20％のグループの獲得賞金が最も大きく…競走馬は大きいほど競走成績はよい」（1983〜2014年生まれ
  約13万頭・Jブログ親）。ただし「体重の重い馬は怪我をする可能性も高い」（J研71）、「体重が重いと、骨折や浅指屈腱炎などの
  怪我をする危険性が高い」（J研79）。
- 新馬・未勝利戦で、2歳9月・3歳9月とも「重いと複勝率が高い」（J研71の表1）。
- 若い馬は短距離ほど軽く、5歳以上は短距離ほど重い（J研79）。
- 2024年の自分の集計（同じ性・年齢の中で5等分）：最も軽い組 勝率4.8%・3着内17.4% → 最も重い組 9.6%・24.8%。

**前走からの増減（JRAの研究：出典なし）**：増減と成績の関係を調べたJRAの資料は見つからなかった。
2024年の自分の集計（参考。頭数から計算した平均の勝率は7.4%、3着内率は22.2%）：

| 増減 | 出走 | 勝率 | 3着内率 |
|---|---:|---:|---:|
| −20kg以下 | 139 | 4.3% | 10.8% |
| −18〜−10 | 2,439 | 6.6% | 19.1% |
| −8〜−4 | 8,889 | 7.3% | 21.2% |
| −2〜＋2 | 16,802 | **7.9%** | **24.4%** |
| ＋4〜＋8 | 8,795 | 7.7% | 22.5% |
| ＋10〜＋18 | 3,387 | 6.3% | 19.9% |
| ＋20以上 | 390 | 6.2% | 16.4% |
| 初出走 | 4,695 | 6.8% | 20.2% |

- **±2kg以内が一番よく、どちらへ大きく動くほど下がる**。ただし差は小さい（10〜18kgの増減で勝率が1.5ポイントほど下がる程度）。
- ⚠️これは**相関で、因果ではない**。大きな増減は長い休み明け・成長期の若い馬に多いはずで（休養期間は今回取っていない）、
  その影響を分けていない。G1だけ（JG1）では＋10kg以上の勝率7.6%・3着内19.9%で、±2kg（6.0%・18.4%）より低くない（422出走と少ない）。
- 実例：シンボリルドルフは弥生賞で「18キログラム増」、皐月賞で「22キログラム減」でどちらも勝った（W馬）。
  オグリキャップは毎日王冠で「8kg増であったため体が重かったのではないか」と騎手が分析している（W馬）。

## 5. 集計の方法（再現用）

- J成績2024：`jra/2024/`の開催日程から「N回○○N日」を拾って282ファイルを取り、PyMuPDFで文字にした。各出走の行
  「馬名＋性＋年齢＋毛色」（例「イズルード牡3栗」）と、その後の「体重＋増減」（例「472＋6」「524± 0」「520 ―」）を読み、
  並び順を着順とした（体重の無い取消・除外は外した）。各レースの「（N頭）」の合計46,016に対し45,667を読めた。
  増減の直後にタイムが続く行（「508＋101：13．8」）は、タイムの分の1桁を増減から外した。
  ⚠️**PDFを文字にすると、セン馬の「せん」が制御文字になる**（G1成績ページで「せん」の馬18頭を照合して確かめた。例：
  チャックネイト→`\x08`6鹿）。制御文字をセン馬として読んだ。名前が行をまたぐ馬は、名前の一部しか取れていない。
- JG1：主なGⅠ18競走の結果ページ（1999年以降で「馬体重」列があるもの）。
- A馬：`data-src/ahonoora/1972〜2024.json.gz`の重賞（アラブ・障害を除く）の出走馬から、1987年までは年12頭・1988年以降は年6頭を
  乱数（種20261127）で選び、馬のページを取った。
- 作業用のスクリプトと取得物は作業場所（scratchpad）にある：`parse_rep.py`・`ana_rep.py`・`parse_bw.py`・`ana_ah.py`。
  ⚠️リポジトリには入れていない。

## 6. ゲームでの使い方の候補（設計ではない。決めるのはユーザー）

CLAUDE.md §0の「プレイヤーの判断が増えるか」「何が締め付けるか」で見た候補。⚠️どれも未合意。

**毛色**
- 割合は§1.2(b)（2024年）をそのまま使える：鹿毛46・黒鹿毛20・栗毛20・青鹿毛7・芦毛6・青毛0.7・栃栗毛0.1・白毛0.07%
  （JRAの2015〜19年夏の資料(a)とも、4区分にまとめれば数ポイントの差）。
  1970〜80年代の世界は(c)のとおり青鹿毛が少なく栃栗毛が多いが、標本が小さい。
- 生まれる馬は§1.3の法則で両親から決める（栗×栗→栗系、芦毛は片親が芦毛のときだけ約半分、白毛は白毛の親からだけ）。
  配合の画面で「この組み合わせなら芦毛が出るかもしれない」が分かる＝**配合の楽しみが1つ増えるが、能力とは無関係**（§1.4）。
- 芦毛は年齢で白くなる（§1.1）。同じ馬の絵が年ごとに変わる＝長く乗った馬の見分けがつく。
- 実名馬はWikipediaか優駿達の蹄跡の毛色を使う（§4）。

**白斑**
- 種類の名前と書き方は§2.1〜2.2で決められる。⚠️**割合の出典は無い**ので、割合を置くなら「根拠なし（仮置き）」と明記して
  ユーザーに決めてもらう必要がある。実名馬の白斑はほぼ取れない（§4）ので、実名馬は白斑なし／ゲームで付ける、のどちらかを選ぶ。
- 一生変わらない（§2.3）＝個体を見分ける目印として使える。

**馬体重**
- 重さ：性・年齢ごとの平均と幅は§3.2の表を使える（例：3歳牡 平均480・幅436〜526、3歳牝 450・404〜498）。2〜5歳で増え、
  4歳秋ごろに止まる。ダートの馬は芝より約12kg重い。
- 増減：2kg刻み。§3.3の分布（±4kg以内が6割、10kg以上が15%、20kg以上が1%強）が「普通の範囲」。
- 調子の手がかりとして：実データでは**増減が小さいほど成績がよく、±10kgを超えると下がる**（§3.5）。ただし差は小さく、
  原因（休み明け・成長）も混ざっている。⭐ゲームでは「大きな増減＝悪い」と決め打ちにせず、**＋10kgが成長分なのか太め残り
  なのかを騎手（プレイヤー）が見分ける**形にすれば、正解が表示される選択にならず判断になる（§0の1）。例：休み明けの＋14kgは
  成長のことも太めのこともある、−10kgは仕上げすぎのこともある——中身は乗るか調教で分かる。
- 季節：牡は夏に軽く冬に重い、牝は春に軽く秋に重い（§3.4）。
- 体重そのものの重い馬は成績がよいが怪我も多い（§3.5）——**落馬・怪我を柱にする方針（§0の2）と結べる**候補。
