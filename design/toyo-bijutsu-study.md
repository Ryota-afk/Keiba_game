# 東美スタディ（東洋美術学校の無料学習サイト）から取り込んだ規則

出典：https://study.to-bi.ac.jp/ （東洋美術学校が2026年7月に公開した無料の学習サイト）
2026-09-05にユーザーの指示で読み込んだ。⚠️**このサイトは「さわって学べる」ことが売りで、
操作して理解する作りになっている。Claudeは文章として書かれている部分しか取り込めていない。**

参照したページ：`/kihon/moji-trainer/`（文字組み）／`/kihon/layout-trainer/`（レイアウト）／
`/kihon/palette-trainer/`（配色）／`/kihon/web-rules/`（Webデザインのルール）

---

## 1. Webデザインのルール（`/kihon/web-rules/`）——⭐最も直接効く

| 規則 | 値 |
|---|---|
| ピクセルは整数で | 13.5pxのような小数を避ける |
| **8pxグリッド** | 余白は8の倍数（8/16/24…）で揃える |
| **タップ領域** | 最低 **44×44px** |
| コントラスト | 本文 **4.5:1以上** |
| 行長 | 全角 **30〜40字**程度 |
| 文字サイズの単位 | 本文は`rem`などの相対単位に対応させる |

## 2. 文字組み（`/kihon/moji-trainer/`）

| 項目 | 値 |
|---|---|
| **行間（本文）** | **160〜190%**（文字サイズの1.7倍前後） |
| 行間（見出し） | 120〜140%まで詰めてよい |
| 字間（本文） | ベタ〜+5% |
| 約物（、。かっこ類） | 字面が半分。**連続したら半角分詰めるのが定石**（例：」「 や 。」） |

用語：仮想ボディ（全文字共通の正方形の箱）／字面（実際に見える部分）／
ベタ組み（箱をそのまま並べる）／ツメ組み（字面に合わせて詰める）。

## 3. レイアウト（`/kihon/layout-trainer/`）

**4原則**：近接（関連するものは近づけ、関係ないものは離す）／整列（見えない線にそろえる）／
反復（色・形・間隔を繰り返す）／コントラスト（大事な所は大きく・強く）。

| 規則 | 値 |
|---|---|
| グループ間の余白 | **4px**（＝8pxグリッドの半分の刻み） |
| **見出しと本文の比** | **1.5〜2倍以上**でハッキリ差をつける |
| 整列 | ⭐**迷ったら左揃え。中央揃えの多用は注意** |

## 4. 配色（`/kihon/palette-trainer/`）

| 規則 | 値 |
|---|---|
| **面積比** | **ベース70：メイン25：アクセント5** |
| 類似色 | ±30° |
| 補色 | 180° |
| トライアド | 120°ずつ |
| コントラスト | 本文 4.5:1以上／大きな見出し 3:1以上 |

## このゲームの実測（2026-09-05）

| 基準 | 実測 | 判定 |
|---|---|---|
| ピクセルは整数 | 級数を5段に畳んで解消済み。⚠️`--fs-world-md: 9.5px`が1つ残る | ほぼ解消 |
| **8pxグリッド** | 余白に**22種類**の値。8の倍数でないものが多数（**14pxが12箇所で最多**） | ⚠️**違反** |
| **タップ領域44×44px** | ⚠️**7件が未達**。タイトル画面の選択肢が**82×42px**と**87×36px**（高さ不足） | ⚠️**違反** |
| 行間160%以上 | `1.35 / 1.4 / 1.5`を使用。本文に使っていれば目安割れ | ⚠️要確認 |
| 見出しは本文の1.5〜2倍 | 26px ÷ 14px ＝ **1.86倍** | ⭐**適合** |
| 左揃え優先 | ⚠️**中央揃え9箇所・左揃え2箇所**。`.title-screen__content`は中身全体を中央揃え | ⚠️**違反** |
| 面積比70:25:5 | 未測定 | 未 |
| コントラスト4.5:1 | 未測定 | 未 |

⚠️**面積比について、このゲームの記録と教科書が食い違っていた。**
`CLAUDE.md`§9は前作の実測を根拠に「面積比を額面どおり満たそうとすると階層が壊れる」と書いている。
⭐**2026-09-05にユーザーが「面積比は教科書通りを目指す」と判断した。** 70:25:5を目標にする。
