# レース画面の馬：毛色・顔の白・脚の白（候補v1・§8手順1）

通しプレイの指摘⑭「馬に個性が無い」の続き。馬のデータ（`horse.coat`・`horse.markings`・年齢）は入ったが、
夢のダービーのレース画面は今も馬番から毛色を決めている（`src/view/dreamDerbySprite.js`の`coatFor`・5色）。
⚠️**候補だけ。`src/`は触っていない。**

- モック：`design/mocks/horse-sprite-v1.html`（`?c=A`／`?c=B`／`?c=C`で切り替え）
- 画像：`design/mocks/horse-sprite-v1-A.png`／`-B.png`／`-C.png`（Playwright・`devices['iPhone 13']`・全体）
- 動きは足していない（今の`hs-gallop`・3コマの脚をそのまま使った）ので、モーションリファレンスは引いていない。

## 1. 3案の違い

| | 案A 今の形のまま、JRAの定義どおり | 案B 遠くから見分けることを優先 | 案C 頭を大きく描き直す |
|---|---|---|---|
| 馬の形 | 変えない | 変えない（たてがみの四角を太くする・尾の先を1つ足す） | 頭を描き直す（面積 約1.5倍） |
| 色の役割 | 胴／影／たてがみ・尾／脚の下半分／鼻先 の5つ | 同じ5つ＋青毛だけ背の明るい線 | 5つ＋背と頬の明るい色 |
| 毛色どうしの差 | 今の色みを基準に控えめ | 明るさ・色みを離す | 案Aと同じ色 |
| 顔の白 | 7種を別の絵・実寸に近い大きさ | 5つの絵にまとめる・大きく描く | 7種を別の絵 |
| 脚の白の高さ（マス） | 1.5／3／5 | 2.5／4.5／7 | 1.5／3.2／5.5・蹄も薄い色 |
| 芦毛 | 3段階（〜3歳／4〜6歳／7歳〜） | 年齢で連続・青みの灰 | 年齢で連続＋白い斑＋元の毛色で色み |
| 影響する他の画面 | なし（色の役割が増えるだけ） | なし | ⚠️`HORSE_BODY`を共有する目覚め〜卒業式の背景（`view/wakeGradScenes.js`）も変わる。タイトル画面は別の絵なので変わらない |

1マス＝SVGのviewBox（40×36）の1単位。レース画面では36×33pxなので1マス＝0.9px（根拠：`DreamDerbyScreen.css`の`.horse-sprite`）。

## 2. 要素の全列挙と取得元

| 要素 | 取得元 | 無いとき |
|---|---|---|
| 胴・首・頭・脚の上半分の色 | `horse.coat`（`data/coat.js`の`COAT_IDS`の8値）→ 新しい色の表 | 下の「欄が無いとき」 |
| 腹の影・耳 | 同上（`shade`） | 同上 |
| たてがみ・尾 | 同上（`mane`・`tail`） | 同上 |
| 脚の下半分 | 同上（`leg`。鹿毛・黒鹿毛・青鹿毛と若い芦毛だけ。他は胴と同じ色） | 同上 |
| 鼻先 | 同上（`muzzle`） | 同上 |
| 顔の白 | `horse.markings.face`（`none`／`star`／`blaze`／`strip`／`starSnip`／`snip`／`bald`） | `none`として描く |
| 脚の白 | `horse.markings.legs`＝`[左前,右前,左後,右後]`・各0〜3 | `[0,0,0,0]`として描く |
| 芦毛の白さ | 年齢＝レースの年−`horse.birthYear`（年齢を出している既存の関数を使う。実装時に関数名を確かめる） | 3歳として描く |
| 芦毛の元の色み（案Cだけ） | `horse.coatGenes.e`（0なら栗毛系＝赤みの灰） | 青みの無い灰 |
| 蹄 | 固定`#221a14`（今のまま）。白毛は薄い色。案Cは白い脚の蹄も薄い色 | — |
| 目・ゼッケン・騎手・帽子・影・自分の馬の輪 | 今のまま（変更なし） | — |

**欄が無いとき**：古いセーブは読み込み直後に`ensureRosterLooks`→`ensureHorseLooks`（`src/domain/horseLooks.js`）が
`coat`・`coatGenes`・`markings`・`frameKg`を補うので、名簿の馬には必ずある。夢のダービー（導入の夢のレース）の
出走馬が名簿の馬でない場合に備え、描く側は`coat`が無ければ今の`coatFor(num)`の5色へ落とす
（鹿毛・黒鹿毛・栗毛・芦毛・青毛の5つを新しい表の同じ毛色に読み替える）。⚠️夢のダービーの出走馬が
`horse.coat`を持っているかは確かめていない（§5の質問1）。

**左右（CLAUDE.md §6）**：馬は右向き＝見えているのは馬の右側。`HORSE_LEGS`の太く長い脚（幅4・高さ9、x=7とx=21）が
手前＝右脚、細く短い脚（幅3・高さ8、x=11とx=25）が奥＝左脚として割り当てた。
`HORSE_LEGS`の添字0〜3 → `markings.legs`の添字 3（右後）・2（左後）・1（右前）・0（左前）。
⚠️「太い脚が手前」は絵の作りからの読み取りで、元のモック（`dream-derby-mock2.html`）に明記は無い。
レース画面が左右反転して描くことは無い（`dreamDerbyEngine.js`に反転なし、と読んだ）。

## 4. 顔の白：実寸で見分けられるか（自分でスクリーンショットを見た結果）

| 案 | 実寸で別の絵に見えたまとまり |
|---|---|
| A | なし／星・星鼻白（額に1点）／流星・作（上の線）／鼻白（鼻先に1点）／白面 — 星と星鼻白、流星と作は拡大しないと分からない |
| B | なし／星／流星・作・星鼻白（同じ絵）／鼻白／白面 — 5つとも実寸で分かる。白面は鼻白と近い |
| C | Aとほぼ同じ。頭が大きいぶん流星と作の線の長さの差は出るが、実寸では小さい |

名前は`FACE_MARKING_LABEL`（`data/coat.js`）のまま。レース画面には名前を出さない（絵だけ）。

脚の白：案A・Cの「微白」（1.5マス＝1.35px）は、鹿毛のような黒い脚の上では細い白い線として見えるが、栗毛では走っている間ほぼ見えない。
案Bの2.5マスは栗毛でも見える。「長白」は全案ではっきり見える。

## 5. ユーザーに決めてもらうこと

1. 夢のダービー（導入の夢）の出走馬は名簿の馬ではないはず。そこにも毛色・模様を決めて入れるか、それとも通常のレース画面だけを対象にするか。
2. 案Cは目覚め〜卒業式の背景の馬の形も変わる。それでよいか（よくなければ案Cの頭はレース画面専用にする＝形の定義が2つになる）。
3. 顔の白を5つの絵にまとめる（案B）ことを許すか。データは7種のまま、絵だけまとめる。
4. 芦毛の年齢の区切りは根拠が無い。3段階（案A）か連続（案B・C）か、何歳でほぼ白にするか。
5. 栗毛のたてがみ：全頭を少し明るく（案A）／はっきり明るく（案B）／馬ごとに濃淡を変える（新しい欄が要る）。
6. 色の表の置き場所：`src/data/dreamDerbyVisuals.js`の`COAT_COLORS`を8毛色×5役割に置き換える想定（実装はまだ）。
