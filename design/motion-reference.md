# モーションリファレンス（動き・イージング辞典）を動きの参考にする

- **出典**：https://motion-reference.takayustudio.jp/ （たかゆ / TakayuStudio・takayustudio.jp）
- **取り込んだ日**：2026-10-11（ユーザー指示「このサイトをゲーム内のモーション参考とするように仕組み化して欲しい」）
- **中身**：動きの名前・速さ・イージングから、作りたい感触を探す辞典。**583件・44分類**（取得日の実測）。
  サイトの説明は「映像・UI・アニメーション制作で動きを設計するための、オリジナルデモによる個人学習用リファレンス」。

## 1. 引き方（道具）

```
node tools/motion-ref.mjs 紙吹雪 着地      # 言葉で探す（名前・用途・感触・説明。複数語はすべて含むもの）
node tools/motion-ref.mjs --cat game-reward   # 分類で絞る
node tools/motion-ref.mjs --id fade-slide     # 1件を詳しく（説明・配分・注意・動きを減らす場合・URL）
node tools/motion-ref.mjs --cats              # 分類の一覧と件数
node tools/motion-ref.mjs --refresh           # サイトを開き直して取り直す
```
- 1件ずつのページは `https://motion-reference.takayustudio.jp/#motion=<id>` で開ける（道具が出す）。
- 道具はイージング名を`src/styles/motion.css`で使う`cubic-bezier(...)`に直して出す（easings.netの表）。
  弾む（bounce・elastic）・ばね（spring）・物理は1本の`cubic-bezier`で表せないので名前だけ出る。
- ⚠️`catalog-`で始まる項目（UIボタン・ゲームHUDなどの分類）は、時間の欄がデモ全体の長さ（2800ms等）に
  なっているものがある。実際の配分はページを開いて確かめる。

## 2. 1件に載っていること
時間・イージング・用途・感触・きっかけ（時間・状態変化／スクロール／タッチ）・配分（何msに何が起きるか）・
見るところ・注意・真似するときのポイント・**動きを減らす場合**（`prefers-reduced-motion`のときの代わりの見せ方）・
実装コード（CSS・WAAPI・GSAP・React・AEの再現）。

## 5. 使うときの決まり
1. **動きを足す・直すときは、作る前にこの道具で同じ用途の項目を2〜3件引き、候補の根拠にする。**
   候補を見せるとき・`devlog/waveNN.md`に書くときは、参考にした項目の**idとURL**を書く
   （「なんとなくの秒数」を置かない。CLAUDE.md §15「数字には根拠」）。
2. **持ち込むのは値と考え方だけ**：時間・イージング・配分・「動きを減らす場合」の考え方。⚠️**サイトの実装コード・
   デモをそのまま貼らない**。利用条件の記載が無く「個人学習用」とあるため、データもリポジトリに入れない
   （道具はOSの一時フォルダにだけ置く）。
3. **値は`src/styles/motion.css`のトークンにする**（生の秒数・`cubic-bezier`をJSX・各画面のCSSに書かない）。
   `prefers-reduced-motion`の扱いは、項目の「動きを減らす場合」を見て決め、`motion.css`の
   `@media (prefers-reduced-motion: reduce)`へ足す。
4. **サイトの値は出発点**。このゲームの画面（スマホ縦・カイロソフト風）で実際に動かして撮って見てから決める
   （CLAUDE.md §14）。`design/sakurai-motion.md`（やり過ぎてちょうど・補間のワナ）と食い違うときは、
   通しプレイで見て決める。
