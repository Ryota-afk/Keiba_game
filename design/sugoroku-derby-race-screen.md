## 1. レース画面の構成（⭐最も参考になる点）

**縦画面を上下2分割。上半分がレース、下半分が出馬表で、⚠️レース中ずっと出馬表が見え続ける。**

### 上半分：レース
- **横スクロール2D**。芝の緑の面、上端に柵とスタンド（茶）。馬はドット絵で横向き
- **上端に馬番のマーカー**（色付きの丸に番号）が横一列に並び、**画面外の馬の位置も分かる**
- **左下に「残り◯m」と「タイム」**が常時表示
- **右下に丸ボタン3つ**（カメラ切替＝先頭／自分、など）
- スタート直後は全馬が縦に重なって見える（枠順の並び）。その後、隊列がばらける
- **画面が追従する対象を切り替えられる**（先頭馬／自分の馬）
- ゴール後：**確定**のオーバーレイ、紙吹雪、ゴール写真、「拡大」「リプレイ」

### 下半分：出馬表（レース中も常時）
列：**馬番（色）／馬名／体力のハート（5個）／性齢／毛色／印（◎○▲△）／人気／斤量／アイコン**
- **自分の馬の行がピンクで強調**
- 途中で「オーナー（COM／自分の名前）」の列に切り替わる場面がある
- 「スキップ」ボタンが右上

## 2. レース前：出走確認とパドック

- **出走確認**：レース名・条件（芝・右・2000m・3歳以上・ハンデ）・賞金の内訳・出走登録馬の一覧と斤量。
  「キャンセル／レースへ」
- **パドック**：**1頭ずつ**カードで見る（1/9…9/9のページ送り）。各馬に
  スプライト・オーナー・ステータス4つ（スピード／スタミナ／瞬発力／根性の数値）・
  脚質・距離適性・装備の枠・特性
- ⭐**自分の馬だけ装備の枠が埋まっている**（他馬は空）

## 3. 結果画面

**着順表**：着順／馬番／馬名／性齢／斤量／オーナー／**タイム・着差**／人気。
1着は自分の馬が強調。

## 4. ホーム画面（参考外だが構造として）

上にスゴロクの盤面とダイス、中に馬のステータス（数値＋円グラフの「調子」108.2%）と特性、
下に**ダイスロール**の大ボタン。⚠️**このゲームの判断はスゴロクにあり、レース中に判断は無い**
（レースは観戦）。

## ⭐ 本作への当てはめ

| スゴダビ | 本作でどう使うか |
|---|---|
| **上レース／下出馬表の常時2分割** | ⭐**採る**。判断カード（1鞍2回）は**下半分の出馬表の場所に差し込む**形が自然——カードが出る瞬間だけ出馬表がカードに置き換わる |
| 上端の馬番マーカー | ⭐**採る**。「包まれた／前が開いた／前が遠い」（状況の5類型）を**マーカーの並びで見せられる** |
| 残り距離＋タイム | 採る |
| カメラ切替（先頭／自分） | 採る。⚠️本作は「自分の馬」固定でよいかもしれない（判断は自分の位置で決まる） |
| スキップ | 採る（既存の設計どおり） |
| パドックで1頭ずつ | ⚠️**本作は違う**——本作の出馬表は「金曜の騎乗確定」で見るもので、**開示されていない能力は見えない**（§3）。1頭ずつ全ステータスを見せる形は採らない |
| 印（◎○▲△） | ⚠️採らない。人気の代わりに**レース傾向の予想**（§5）を出すほうが本作の判断に繋がる |
| 体力のハート | ⚠️採らない（CLAUDE.md §8：絵文字・アイコンで階層を作らない）。疲労は別の見せ方 |
| 結果の着差・タイム | 採る |

⚠️**画面デザインそのもの（配置の寸法・絵柄・文言）は写さない**（`rights-check.md`§2-6）。
採るのは「上下2分割で出馬表が常時見える」「馬番マーカーで隊列を読む」という**構造**。
