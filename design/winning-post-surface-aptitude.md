# ウイニングポスト 馬場適性の実測（◎○△×が着順とスピードに換算してどれだけか）

出典：上岡ゲームズ（kamioka-games.com/1596/）「馬場適性による着順とスピード換算の調査」。
2026-09-16にユーザーが本文を貼った（「参考にしてみてね」）。
⚠️`design/rights-check.md`の承認済み出典ではないが、**ここに収めるのは枠組みと量の目安**で、
ウイポのデータそのものではない（ゲーム内の値を測った第三者の実測記事）。
⚠️CLAUDE.md §0.5「データの丸写しはしない」の扱いは`winning-post-race-model.md`と同じ。

## 調査条件（出典側）

- ベースは同じ競走馬。スピード70（B相当）・サブパラすべてB・脚質自在・気性普通・性格普通。
- 馬場適性だけを変えた4種類（◎○△×）を各4頭、計16頭。
- 東京芝2000m（良）・枠順ランダム・20回走らせて平均着順を取る。

## 結果1：適性ごとの平均着順の差（16頭立て）

| 比べる組 | 平均着順の差 |
|---|---|
| ◎ と ○ | 約2.4着 |
| **○ と △** | **約5.1着** |
| △ と × | 約2.2着 |

⭐**○と△の間だけが他の2つの約2倍開いている。** ◎○△×は等間隔ではない。
⚠️合計すると◎と×は約9.7着差。16頭立ての平均着順は8.5着なので、4段の平均着順は
逆算すると**◎3.6着・○6.0着・△11.1着・×13.3着**あたりになる（出典はグラフのみで
数表は無いため、差の3つから逆算した値）。

## 結果2：スピードに換算するとどれだけか

低いほうの適性の馬のスピードを何ポイント足せば互角になるかを、9頭対9頭で測ったもの。

| 比べる組 | スピード換算 |
|---|---|
| ◎ と ○ | 約+3 |
| ○ と △ | 約+4 |
| △ と × | 約+2 |

⚠️**△が◎に挑むにはスピード+7が要る**＝実用的でない。出典の結論は
「適性◎が多いレースに挑むには最低でも○、さらにスピードも+3は上回っていること」。

⚠️⚠️**このスピード換算は本作にそのまま持ち込めない。** ウイポのスピードは0〜100前後の
主要能力で、+3〜4が着順を大きく動かす。本作のスピードは1項目だけをG→S+（0→100）に
振り切っても芝1800mで2.09着しか動かない（`devlog/wave08.md`§7-1の実測）ので、
「スピード+3」は本作では0.06着にしかならない。⭐**持ち込むのは結果1（平均着順）と、
○と△の間だけが2倍開いているという形のほう。**
